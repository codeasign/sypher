  participant C as Client

  C->>E: 1. Create lease (TTL 10s)
  E->>C: Lease ID: 0xdeadbeef
  C->>E: 2. Create key with lease<br/>PUT /locks/resource_A<br/>value: client_7<br/>lease: 0xdeadbeef
  E->>C: Created (via Raft consensus)
  C->>E: 3. Periodic lease refresh

  C->>E: 4. Release lock<br/>DELETE /locks/resource_A<br/>Revoke lease 0xdeadbeef
  E->>C: Released
  Note over C,E: On crash:<br/>lease expires after 10s<br/>key auto-deleted by etcd<br/>next waiter can acquire
