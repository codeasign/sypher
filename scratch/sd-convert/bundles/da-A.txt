sequenceDiagram
  participant B as Browser
  participant A as Dashboard API
  participant R as Redis Cache
  B->>A: POST /api/query
  A->>R: hash(query_string +<br/>time_range)
  Note over A: MISS<br/>No entry found
  A->>R: Query TSDB
  R-->>A: Result
  A->>R: SET key result TTL=30s
  A-->>B: Return result
  Note over B,R: (Next request, same query within 30s)
  Note over A: HIT<br/>Return cached result
  A-->>B: Return cached result
  Note over B,R: Cache hit: 1ms (vs 100ms for TSDB)<br/>Cache hit rate: 60-85%
