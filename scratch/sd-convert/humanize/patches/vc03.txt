Vector clocks still play a role: they detect when a CRDT merge is needed. When two CRDT states have concurrent vector clocks, the system merges them using the CRDT's merge function instead of application-level resolution.
====
Vector clocks can still play a role: they detect when a CRDT merge is actually needed. When two CRDT states have concurrent vector clocks, the system merges them using the CRDT's merge function instead of application-level resolution. Because a state-based CRDT merge is safe to apply to any pair of states, the clock is mostly an optimization that lets the system skip work when one state already includes the other.
