<<<<
A single product's order data is on one shard because orders are sharded by `order_id` or `product_id`.
====
A hot product can only concentrate load on one shard if that product's rows are placed together, for example when the table is sharded by `product_id` or by a seller ID. If orders were sharded by `order_id`, look elsewhere: a single very large customer or seller, a runaway batch job, a bad query plan, or a degraded host (noisy neighbor, failing disk). Confirm the shard key first, then find the hot key from the query logs.
