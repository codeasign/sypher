====
A single PostgreSQL instance is often called CA. It is consistent (one copy of the data) and available while it is running. With a single node, there is no network between replicas to partition, so the CAP theorem does not really apply. If the node fails, the system is unavailable, but that is an ordinary failure, not a partition.
