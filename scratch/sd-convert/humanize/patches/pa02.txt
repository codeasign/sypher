Complexity: Each hinted handoff write is O(1) on the live node (append to buffer). Delivery is O(N) where N is the number of pending hints. The buffer size grows with the number of concurrent failures and write rate; typical production limits cap buffered hints to 1GB per node.

Complexity: Each hinted handoff write is O(1) on the live node (append to buffer). Delivery is O(N) where N is the number of pending hints. The buffer size grows with the number of concurrent failures and write rate, so systems limit how much they will buffer.

Cassandra rebuilds Merkle trees every 5 to 30 minutes per table. The tree size is configurable; 64 to 256 leaves per node is typical.
====
In Cassandra, Merkle trees are built on demand when a repair runs, not continuously, and repair is typically scheduled to run at least once within the tombstone grace period. Tree depth is bounded so that building it stays affordable.

If quorum is lost (e.g., 2 of 3 replicas down), the system stops accepting writes and returns errors. Strongly consistent reads also need a majority, so they fail too. Only reads that accept possible staleness can still be served by a surviving replica.
