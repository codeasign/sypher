- **Incarnation number**: A monotonically increasing counter owned by the node itself. It is bumped when the node restarts, and in SWIM also when the node refutes a suspicion about itself. Higher incarnation numbers supersede lower ones, preventing stale state from older incarnations from overwriting current state. (Cassandra uses a similar "generation" value based on the node's start time.)

1. **Expected convergence rounds:** With fan-out F, the expected number of rounds to inform all N nodes is approximately log_F(N) + O(1). The base of the logarithm is the fan-out.

2. **Probability of full convergence:** Given enough rounds, gossip converges with probability approaching 1. The probability that a specific node remains uninformed after R rounds with fan-out F is approximately (1 - F/N)^(F × R) for the first few rounds.

3. **Message complexity:** Each round generates O(N × F) messages (each of N nodes contacts F peers). Over R rounds, the total is O(N × F × R) = O(N × log(N)). This is the key scalability property: total messages grow linearly with N, not quadratically.
====
1. **Expected convergence rounds:** With fan-out F, the expected number of rounds to inform all N nodes is approximately log_(F+1)(N) + ln(N)/F. The first term is the exponential spreading phase and the second is the tail in which the last few nodes are found by chance.

2. **Probability of full convergence:** Given enough rounds, gossip converges with probability approaching 1. Once most nodes are informed, the chance that a particular node is still uninformed shrinks by a factor of about e^(-F) each round, so it decays exponentially. There is always a small chance that a given node is missed in any fixed number of rounds, which is why repeated exchanges (anti-entropy) matter.

3. **Message complexity:** Each round generates O(N × F) messages (each of N nodes contacts F peers). Over R rounds, the total is O(N × F × R) = O(N × log(N)) to spread one piece of information. Per node, that is only O(log N) messages per rumor, and the per-round load on each node stays constant. Compare this with all-to-all broadcast, which needs on the order of N² messages.
