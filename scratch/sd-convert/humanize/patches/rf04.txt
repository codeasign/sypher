Raft ensures at-least-once delivery by default.

**Better approach:** Include a unique request ID in each client request. The Raft state machine deduplicates based on request IDs, providing exactly-once semantics.
====
A client that retries after a timeout gets at-least-once behavior by default.

**Better approach:** Include a unique request ID in each client request. The Raft state machine deduplicates based on request IDs (a session table records the last result per client), providing effectively-once semantics.
