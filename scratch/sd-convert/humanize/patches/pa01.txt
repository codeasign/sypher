**Quorum**: The minimum number of replicas that must participate in a read or write for the operation to succeed. Write-all/read-one provides strong consistency. Write-one/read-all provides low latency.
====
**Quorum**: The minimum number of replicas that must participate in a read or write for the operation to succeed. If the number of replicas read (R) plus the number written (W) exceeds the replication factor, reads see the latest write. Write-all/read-one and write-one/read-all both satisfy this, and they simply move the latency cost to writes or to reads.
