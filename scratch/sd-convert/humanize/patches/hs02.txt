**Time complexity**: O(1) per request. O(n) for distributed token synchronization.

A local token bucket per node allows N times the intended global rate. A distributed token bucket needs a shared counter that is updated atomically, usually in Redis. It does not need consensus, but it adds a network round trip to every request.

**Time complexity**: O(1) per request, plus one network call to the shared store in the distributed version.
