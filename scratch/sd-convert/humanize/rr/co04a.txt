### Failure 5: Even-Sized Clusters and Broken Quorums

An even-sized cluster (2 or 4 nodes) is not more fault tolerant than the next smaller odd size, and it can stall on an even split. A 4-node cluster needs 3 votes for a quorum, so it tolerates only 1 failure, the same as a 3-node cluster, and a 2-2 network partition leaves neither side with a majority, so the whole cluster stops accepting writes. Split-brain itself comes from a broken quorum rule, for example a quorum computed as N/2 instead of N/2 + 1, or membership changes made unsafely (adding several nodes at once, or adding a node without removing a dead one) so that two disjoint groups each believe they hold a majority.

Cause: Using an even number of consensus nodes, or cluster membership misconfiguration.

Mitigation: Use an odd number of consensus nodes, change membership one node at a time, and rely on an implementation that enforces a majority of the current configuration.
