## Page purpose

No new content here — just the closing checkpoint. Read back through the progression below and confirm each line is genuinely true for you, not just something you recognize.

## The progression

- **I know how to test traditional applications** — the starting point this course assumed, back in the course overview.
- **I understand how AI applications behave** — Module 1's four shapes, and Module 1's list of concrete ways AI applications differ from deterministic software.
- **I can design tests for LLM applications** — Module 3's prompt testing vs. output validation split, and the test-oracle problem for a system with no single correct answer.
- **I can evaluate LLM and RAG quality** — Modules 6 through 11: rule-based checks, semantic similarity, LLM-as-a-judge, evaluator validation, and RAG-specific groundedness and citation checks.
- **I can test AI security and reliability** — Module 12's safety suite and Module 16's operational-quality testing, kept as two distinct concerns throughout.
- **I can automate AI regression testing** — Modules 13 and 14: a baseline, a comparison, and a real distinction between five different sources of regression.
- **I can integrate AI quality gates into CI/CD** — Module 19's two-path pipeline, and a gate that actually blocked a release on a real safety regression.
- **I can explain and defend my AI Quality Engineering strategy** — Module 22's engineering judgment, Module 23's troubleshooting under real conditions, and Module 24's portfolio and interview preparation.

## What you built

The **LLM Quality & Evaluation Framework** — fifteen milestones, from a single local model call in Setup to a CI-gated, safety-tested, regression-monitored evaluation pipeline with its own validated evaluator and its own documented engineering trade-offs. Not a tutorial project you followed along with once — a working toolkit you can point to, explain, and extend.

## The one distinction, one last time

"Using AI to improve testing" and "testing AI systems" are different activities. This course was almost entirely the second one, and if there's a single thing worth carrying forward past this page, it's knowing which one you're doing at any given moment — and testing accordingly.
