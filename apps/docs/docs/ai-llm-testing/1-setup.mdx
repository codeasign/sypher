## Page purpose

This page gets a real, local language model running on your machine and confirms you can talk to it — nothing more. By the end, you will have Ollama installed, a model downloaded and responding to prompts, and a Python environment ready for Module 1. This is Milestone 1 of the LLM Quality & Evaluation Framework: run a local model.

## Learning objectives

By the end of this page, you should be able to:

- Explain in plain language what Ollama does and why this course uses it instead of a cloud API.
- Install Ollama, pull a model, and get a response from it on the command line.
- Set up a Python virtual environment with the packages this course uses.
- Diagnose the most common reason a first Ollama call fails.

## Why a local model, in plain language

Every module in this course needs to send prompts to a language model and look at what comes back — sometimes dozens of times in a row while you're iterating on a test. If that model lived in the cloud, every one of those calls would cost money and depend on your internet connection. **Ollama** is a free tool that runs a language model directly on your own computer, so you can call it as many times as you want, for free, even offline. It's not what most companies run in production — but as a place to *learn how AI systems behave and fail*, it's ideal: fast to iterate on, free to hammer with test runs, and fully under your control.

**Terminology, before you install anything:**

- **Model** — the AI itself: a file (or set of files) containing everything the LLM needs to generate text. You "pull" (download) one before you can use it.
- **Ollama server** — a small background program that loads a model into memory and answers requests sent to it, over HTTP, on your own machine (`localhost:11434`).
- **Prompt** — the text you send the model.
- **Completion / response** — the text the model sends back.
- **Local inference** — running the model yourself, on your own hardware, instead of calling someone else's API.

## Install Ollama

Download the installer for your operating system from Ollama's website and run it. On Windows and macOS it installs as a background application; on Linux you can install it with:

```bash
curl -fsSL https://ollama.ai/install.sh | sh
```

Confirm it installed correctly:

```bash
ollama --version
```

You should see a version number printed back. If you see `command not found`, the install didn't complete, or your terminal needs to be restarted to pick up the new PATH entry.

## Pull and run your first model

This course uses **`llama3.2:3b`** as its running example model — small enough to run comfortably on a laptop, capable enough to produce realistic, useful, and realistically *imperfect* output, which is exactly what you need for a testing course. Pull it:

```bash
ollama pull llama3.2:3b
```

This downloads a few gigabytes, so it can take a few minutes depending on your connection. When it finishes, run a single-shot prompt directly from the command line:

```bash
ollama run llama3.2:3b "In one sentence, what does a QA engineer do?"
```

**Run it now before continuing.** You should see a sentence or two of generated text printed to your terminal within a few seconds.

### Explaining the result

What you just did: your terminal sent the text `"In one sentence, what does a QA engineer do?"` to the Ollama server running on your machine, the server loaded `llama3.2:3b` into memory, ran inference, and streamed the generated text back to your terminal. No network request left your computer. If you run the exact same command again, you'll likely get a *differently worded* sentence back — that's not a bug, and it's the first thing this course is going to teach you to test around, starting in earnest in Module 3.

## Set up the Python environment

The rest of this course calls the model from Python, not the command line. Create a project folder and a virtual environment:

```bash
mkdir llmqe && cd llmqe
python -m venv venv
```

Activate it:

```bash
# macOS/Linux
source venv/bin/activate

# Windows (PowerShell)
venv\Scripts\Activate.ps1
```

Install the packages this course relies on:

```bash
pip install ollama pytest
```

- `ollama` — the official Python client for talking to your local Ollama server.
- `pytest` — the test runner every test in this course uses; if you've written Python tests before, you've likely already used it.

Confirm it works with a three-line script:

```python
# check_setup.py
from ollama import chat

response = chat(model="llama3.2:3b", messages=[{"role": "user", "content": "Say hello in five words or fewer."}])
print(response.message.content)
```

Run it:

```bash
python check_setup.py
```

If you see a short greeting printed to your console, your environment is ready.

## Diagnosing a first-run failure

It's common — almost expected — for this not to work cleanly the very first time. Rather than skip past that, walk through it once, the way you will for real failures throughout this course.

**Symptom:** running `check_setup.py` raises `ConnectionError` (or the `ollama` package's equivalent), instead of printing a greeting.

**Hypothesis:** the Python client can't reach the Ollama server — most likely because the server isn't running.

**Investigation:** check whether the server is listening on its default port.

```bash
curl http://localhost:11434
```

**Evidence:** if this also fails to connect, the Ollama server itself isn't running, even though the client and model were both installed correctly in the earlier steps.

**Root cause:** on Linux (and sometimes after certain Windows/macOS installs), Ollama doesn't always start itself automatically the way it does after a fresh install elsewhere — it has to be started explicitly.

**Fix:** start the server in its own terminal window and leave it running:

```bash
ollama serve
```

Then re-run `check_setup.py` in a separate terminal.

**Prevention:** before debugging *anything* in this course that involves a model call, check that the server is actually up — it's the first thing to rule out, every time, and it will save you from chasing a phantom bug in your own code that was never there.
