# Search Algorithms

*Estimated completion time: 12 to 18 hours*

**Difficulty:** Beginner friendly, no prior algorithms experience needed

## What this course covers

A beginner-friendly course covering the search algorithms every engineer should know cold, from a plain linear scan to `A*` pathfinding, written for total beginners first. Each module is a single self-contained page written in plain English, with an everyday analogy, an ASCII diagram walking through a real example step by step, and a plain-language "How It Works" explanation of how fast the algorithm is. Every module also has an interactive in-browser code editor supporting nine languages (Python, C, C++, Java, C#, JavaScript, TypeScript, Rust, and Go), plus a full set of worked solutions.

New to algorithms? Start with Module 0. It covers Big-O notation and what "sorted" means in plain language before the algorithm modules assume you know them.

## Why this matters

Search shows up everywhere: database indexes, autocomplete, pathfinding in a map app, technical interviews. Knowing more than "loop through the array" is what separates code that works on small inputs from code that still works at scale, and it's one of the most reliably asked topics in technical interviews. This course builds that intuition from a plain linear scan all the way to weighted-graph pathfinding, with a worked example and runnable code at every step.

## Skills you will gain

- Explain Big-O notation and why an algorithm's growth rate matters more than its exact runtime
- Implement linear, binary, and binary-search-variant algorithms (first/last occurrence, rotated arrays)
- Choose between ternary, jump, interpolation, and exponential search for the right input shape
- Implement depth-first and breadth-first search over graphs and trees
- Implement `A*` search with a heuristic for weighted-graph pathfinding
- Apply two-pointer, binary-search-on-answer, and matrix search patterns to real problems
- Implement search over specialized structures: graphs, trees, and tries

## Prerequisites

- No prior algorithms experience required; Module 0 covers the vocabulary you need
- Basic comfort reading code in at least one programming language

## How to use this course

Module 0 is a beginner primer: no code, just the vocabulary (Big-O notation, what "sorted" means) that every later module assumes. Skip it if you already know these terms. Every module after that (1-18) follows the same five-part format: Summary, Pseudocode, ASCII Diagram, How It Works, and Practice test cases, followed by an interactive code editor (9 languages) and a Solutions section with a worked answer in each. Work through modules 1-7 first; each builds on plain array-search fundamentals. Modules 8-10 shift to graph/tree traversal, ending with weighted-graph traversal plus heuristics. Modules 11-18 cover pointer, grid, and structure-based search patterns (two pointers, matrices, rotated arrays, graphs, trees, and tries) common in real-world code and technical interviews.
