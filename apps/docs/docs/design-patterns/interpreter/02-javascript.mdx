## Implementation

Below is a complete JavaScript ES2022+ implementation of the Interpreter pattern using a Stock Market domain. The pattern defines a grammar for stock-filtering expressions and evaluates them against stock data. `Expression` is the abstract interface, concrete terminal expressions (`PriceGreaterThan`, `VolumeGreaterThan`, `TickerEquals`, `SectorEquals`) handle atomic comparisons, and nonterminal expressions (`AndExpr`, `OrExpr`, `NotExpr`) compose them into complex queries. The `StockScreener` client iterates over a portfolio and collects matching stocks.

### How the Implementation Works

#### Class Diagram (Pseudocode)

```
// ── Participant Diagram ──
//
//   ┌──────────────────────────────────────┐
//   │   <<interface>>                      │
//   │   Expression (AbstractExpression)    │ ← OOP: Abstraction
//   ├──────────────────────────────────────┤    ISP: single interpret()
//   │   + interpret(stock): boolean        │     method only
//   └────────────────┬─────────────────────┘
//                    ▲ implements
//   ┌────────────────┴─────────────────────┐
//   │                │                     │
//   ┌────────────────┐  ┌──────────────────┐
//   │ TerminalExprs  │  │ NonterminalExprs │ ← OOP: Polymorphism
//   │ (PriceCheck,   │  │ (AndExpr,        │    LSP: all are
//   │  VolumeCheck,  │  │  OrExpr,         │    substitutable for
//   │  TickerMatch,  │  │  NotExpr)        │    Expression
//   │  SectorMatch)  │  │                  │
//   └────────────────┘  └──────────────────┘
//
//   ┌──────────────────────────────────────┐
//   │ StockScreener (Client)               │ ← OOP: Encapsulation
//   ├──────────────────────────────────────┤    SRP: single reason
//   │ + screen(stocks, expr): Stock[]      │     to change
//   └──────────────────────────────────────┘    DIP: depends on
//                                               Expression abstraction
```

#### OOP Concepts Applied

1. **Abstraction** — `Expression` defines the `interpret()` contract. All clients depend on `Expression`, never on concrete expression types.
2. **Encapsulation** — Each expression class hides its internal data (thresholds, ticker strings, child expressions) behind the `interpret()` method.
3. **Inheritance** — Terminal and nonterminal expression classes implement the `Expression` interface, sharing the common contract.
4. **Polymorphism** — The `StockScreener.screen()` method calls `interpret()` on any `Expression` without knowing the concrete type. The correct evaluation runs per type.

#### SOLID Principles Applied

5. **SRP** — Each expression class has exactly one job: evaluate one specific grammar rule. `StockScreener` only iterates and collects.
6. **OCP** — Adding a new expression type (e.g., `PriceLessThan`) requires adding a new class that implements `Expression`. No existing code is modified.
7. **LSP** — Every concrete expression can substitute `Expression` without breaking the client. The screener treats all expressions uniformly.
8. **ISP** — The `Expression` interface is a single method — `interpret()`. No class is forced to implement methods it does not need.
9. **DIP** — `StockScreener` depends on the `Expression` abstraction, not on concrete expression classes.

### StockData (Context)

```javascript
// ── Context ──
class StockData {
  constructor(ticker, price, volume, sector) {
    this.ticker = ticker;
    this.price = price;
    this.volume = volume;
    this.sector = sector;
  }
}
```

### Expression (AbstractExpression)

```javascript
// ── Abstract Expression ──
class Expression {
  interpret(stock) {
    throw new Error('Subclasses must implement interpret()');
  }
}
```

### PriceGreaterThan (TerminalExpression)

```javascript
class PriceGreaterThan extends Expression {
  constructor(threshold) {
    super();
    this.threshold = threshold;
  }

  interpret(stock) {
    return stock.price > this.threshold;
  }
}
```

### VolumeGreaterThan (TerminalExpression)

```javascript
class VolumeGreaterThan extends Expression {
  constructor(threshold) {
    super();
    this.threshold = threshold;
  }

  interpret(stock) {
    return stock.volume > this.threshold;
  }
}
```

### TickerEquals (TerminalExpression)

```javascript
class TickerEquals extends Expression {
  constructor(ticker) {
    super();
    this.ticker = ticker.toUpperCase();
  }

  interpret(stock) {
    return stock.ticker === this.ticker;
  }
}
```

### SectorEquals (TerminalExpression)

```javascript
class SectorEquals extends Expression {
  constructor(sector) {
    super();
    this.sector = sector;
  }

  interpret(stock) {
    return stock.sector === this.sector;
  }
}
```

### AndExpr (NonterminalExpression)

```javascript
class AndExpr extends Expression {
  constructor(left, right) {
    super();
    this.left = left;
    this.right = right;
  }

  interpret(stock) {
    return this.left.interpret(stock) && this.right.interpret(stock);
  }
}
```

### OrExpr (NonterminalExpression)

```javascript
class OrExpr extends Expression {
  constructor(left, right) {
    super();
    this.left = left;
    this.right = right;
  }

  interpret(stock) {
    return this.left.interpret(stock) || this.right.interpret(stock);
  }
}
```

### NotExpr (NonterminalExpression)

```javascript
class NotExpr extends Expression {
  constructor(expr) {
    super();
    this.expr = expr;
  }

  interpret(stock) {
    return !this.expr.interpret(stock);
  }
}
```

### StockScreener (Client)

```javascript
// ── Client ──
class StockScreener {
  screen(stocks, expression) {
    const results = [];
    for (const stock of stocks) {
      if (expression.interpret(stock)) {
        results.push(stock);
      }
    }
    return results;
  }
}
```

### Main / Driver

```javascript
// ── Main / Driver ──
const stocks = [
  new StockData('AAPL', 175.50, 85000000, 'Technology'),
  new StockData('GOOGL', 142.30, 32000000, 'Technology'),
  new StockData('MSFT', 378.90, 25000000, 'Technology'),
  new StockData('JPM', 198.40, 12000000, 'Financial'),
  new StockData('BAC', 39.20, 45000000, 'Financial'),
  new StockData('AMZN', 178.25, 61000000, 'Technology'),
  new StockData('TSLA', 245.60, 98000000, 'Automotive'),
  new StockData('WMT', 72.80, 18000000, 'Retail'),
  new StockData('V', 275.30, 15000000, 'Financial'),
  new StockData('NVDA', 820.10, 52000000, 'Technology'),
];

const screener = new StockScreener();

console.log('=== Stock Screener — Interpreter Pattern ===');
console.log('');

// Query 1: price > 150 AND volume > 30000000
const query1 = new AndExpr(
  new PriceGreaterThan(150.0),
  new VolumeGreaterThan(30000000)
);
const result1 = screener.screen(stocks, query1);
console.log('Query 1: price > 150 AND volume > 30000000');
result1.forEach(s => console.log(`  ${s.ticker} — $${s.price} — ${(s.volume / 1000000).toFixed(1)}M vol`));
console.log(`  Matched: ${result1.length} stocks`);
console.log('');

// Query 2: sector = "Financial" OR ticker = "MSFT"
const query2 = new OrExpr(
  new SectorEquals('Financial'),
  new TickerEquals('MSFT')
);
const result2 = screener.screen(stocks, query2);
console.log('Query 2: sector = "Financial" OR ticker = "MSFT"');
result2.forEach(s => console.log(`  ${s.ticker} — $${s.price} — ${s.sector}`));
console.log(`  Matched: ${result2.length} stocks`);
console.log('');

// Query 3: NOT (price < 100)
const query3 = new NotExpr(
  new PriceGreaterThan(100.0) // actually: NOT (price <= 100) = price > 100
);
// Rebuild as: NOT (price <= 100) — we need a PriceLessThanOrEqual, but
// we can simulate: NOT (price > 100) = price <= 100, so NOT(NOT(price > 100)) = price > 100
// Let's just use: NOT(price > 100) means price <= 100, so we want stocks with price <= 100
const query3b = new NotExpr(new PriceGreaterThan(100.0));
const result3 = screener.screen(stocks, query3b);
console.log('Query 3: NOT (price > 100) — stocks with price <= 100');
result3.forEach(s => console.log(`  ${s.ticker} — $${s.price}`));
console.log(`  Matched: ${result3.length} stocks`);
console.log('');

// Query 4: (ticker = "AAPL" OR ticker = "GOOGL") AND volume > 40000000
const query4 = new AndExpr(
  new OrExpr(
    new TickerEquals('AAPL'),
    new TickerEquals('GOOGL')
  ),
  new VolumeGreaterThan(40000000)
);
const result4 = screener.screen(stocks, query4);
console.log('Query 4: (ticker = "AAPL" OR ticker = "GOOGL") AND volume > 40000000');
result4.forEach(s => console.log(`  ${s.ticker} — $${s.price} — ${(s.volume / 1000000).toFixed(1)}M vol`));
console.log(`  Matched: ${result4.length} stocks`);
console.log('');

// Query 5: sector = "Technology" OR sector = "Financial"
const query5 = new OrExpr(
  new SectorEquals('Technology'),
  new SectorEquals('Financial')
);
const result5 = screener.screen(stocks, query5);
console.log('Query 5: sector = "Technology" OR sector = "Financial"');
result5.forEach(s => console.log(`  ${s.ticker} — $${s.price} — ${s.sector}`));
console.log(`  Matched: ${result5.length} stocks`);
```

### Language-Specific Notes

- **OOP concepts** — JavaScript uses prototype-based inheritance, but ES2022+ `class` syntax provides a familiar class-based interface. The `extends Expression` establishes the contract, and `super()` in the constructor initializes the base class.
- **SOLID in practice** — JavaScript's dynamic typing makes DIP and LSP natural: any object with an `interpret()` method can substitute for `Expression`. The `StockScreener` never checks types, relying on duck typing.
- **Idiomatic patterns** — JavaScript's `Array.prototype.forEach()` and `for...of` loops are used for iteration. Template literals (`${}`) provide clean string formatting for output. The `toUpperCase()` call in `TickerEquals` normalizes input for case-insensitive comparison.
- **No `instanceof` checks** — The screener's `screen()` method calls `interpret()` polymorphically without any type checking, demonstrating the purest form of the pattern.
