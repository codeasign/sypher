## Page purpose

This page gets a real local model responding to you, and a real RAGAS import working, before Module 1 starts. That's the whole bar — no framework code yet, just a working environment you can trust.

## Learning objectives

By the end of this page, you should be able to:

- Get a real response from a local Ollama model, from both the command line and Python.
- Set up a Python environment with RAGAS installed and importable.
- Explain why this course pins a specific `langchain-community` version.

## Install Ollama and pull a model

Download and install Ollama for your OS from its website, then confirm it installed:

```bash
ollama --version
```

Pull and run this course's model:

```bash
ollama pull llama3.2:3b
ollama run llama3.2:3b "In one sentence, what does a QA engineer do?"
```

**Run it now.** You should see a sentence or two of generated text within a few seconds. If it hangs or refuses to connect, start the server explicitly in its own terminal and try again:

```bash
ollama serve
```

## Set up the Python project

```bash
mkdir aiqe-ragas && cd aiqe-ragas
python -m venv venv
```

Activate it:

```bash
# macOS/Linux
source venv/bin/activate

# Windows (PowerShell)
venv\Scripts\Activate.ps1
```

Install the Ollama client and confirm a real response from Python:

```bash
pip install ollama
```

```python
# check_ollama.py
import ollama

response = ollama.chat(model="llama3.2:3b", messages=[{"role": "user", "content": "Say hello in five words or fewer."}])
print(response.message.content)
```

```bash
python check_ollama.py
```

**Run it now.** A short greeting printed to your console means your local model connection works.

## Install RAGAS

```bash
pip install ragas "langchain-community<0.4" langchain-ollama
```

**Use this exact command, not a plain `pip install ragas`.** Here's why: at the time this course was written, a bare `pip install ragas` resolves the newest `langchain-community` release available, but that release has dropped an internal module RAGAS's own code still imports directly — the import fails with `ModuleNotFoundError: No module named 'langchain_community.chat_models.vertexai'` the moment you try to use RAGAS, even though the install itself reported success. Pinning `langchain-community<0.4` keeps you on a version that still has it. If you hit that exact error anyway, this pin is the fix.

Confirm the import actually works:

```python
# check_ragas.py
import ragas
from ragas import evaluate, EvaluationDataset
from ragas.metrics import Faithfulness
from ragas.llms import LangchainLLMWrapper

print("ragas version:", ragas.__version__)
print("imports OK")
```

```bash
python check_ragas.py
```

**Run it now.** You'll likely see one or more `DeprecationWarning` lines — RAGAS is mid-migration to a newer internal API (you'll see this again starting in Module 6). They're expected and don't indicate a problem; `print("imports OK")` actually printing is the real confirmation you need.
