# Sorting Algorithms

*Estimated completion time: 8–12 hours*

**Difficulty:** Beginner friendly, no prior algorithms experience assumed

## What This Course Covers

A beginner-friendly course covering the sorting algorithms every engineer eventually runs into — from the simplest comparison sorts to the hybrid algorithm powering every modern language's built-in sort. Each module is a single self-contained page written in plain English, with an everyday analogy, an ASCII diagram walking through a real pass step by step, and a plain-language explanation of how fast the algorithm is and how much memory it needs. Every module also has an interactive in-browser code editor supporting nine languages — Python, C, C++, Java, C#, JavaScript, TypeScript, Rust, and Go — plus a full set of worked solutions.

New to algorithms? Start with Module 0 — it covers Big-O notation, stability, and in-place sorting in plain language before the algorithm modules assume you know them.

## Why This Matters

Every language's built-in `sort()` is a sorting algorithm someone had to design and reason about — and knowing why Tim Sort exists, or when a non-comparison sort like Radix Sort beats anything comparison-based, is what turns "sorting is a solved problem" into an actual engineering decision. It's also one of the most commonly asked topics in technical interviews. This course builds that judgment from the ground up, with a worked example and runnable code for every algorithm.

## Skills You Will Gain

- Explain Big-O notation, stability, and in-place sorting, and why each matters when choosing an algorithm
- Implement the fundamental O(n²) comparison sorts: Bubble, Selection, and Insertion Sort
- Implement O(n log n) divide-and-conquer and heap-based sorts: Merge, Quick, and Heap Sort
- Implement non-comparison sorts — Counting, Radix, and Bucket Sort — and know when they beat O(n log n)
- Explain Shell Sort as an Insertion Sort generalization and Tim Sort as the hybrid real languages use
- Choose the right sorting algorithm for a given constraint (stability, memory, input distribution)

## Prerequisites

- No prior algorithms experience required — Module 0 covers the vocabulary you need
- Basic comfort reading code in at least one programming language

## How to Use This Course

Module 0 is a beginner primer — no code, just the vocabulary (Big-O notation, stability, in-place) that every later module assumes. Skip it if you already know these terms. Every module after that (1-11) follows the same five-part format: Summary, Pseudocode, ASCII Diagram, How It Works, and Practice test cases — followed by an interactive code editor (9 languages) and a Solutions section with a worked answer in each. Work through modules 1-3 first — the simple O(n^2) comparison sorts that set up every idea that follows. Modules 4-6 cover the O(n log n) divide-and-conquer and heap-based sorts. Modules 7-9 shift to non-comparison sorts that beat O(n log n) under specific constraints. Module 10 covers Shell Sort as an Insertion Sort generalization, and module 11 covers Tim Sort — the hybrid every mainstream language actually uses. Module 12 is a decision guide for picking the right algorithm given a real constraint.
