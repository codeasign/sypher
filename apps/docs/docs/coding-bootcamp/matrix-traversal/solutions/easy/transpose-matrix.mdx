# Transpose Matrix — Solution

## Problem Overview

Given an R×C matrix, produce its transpose — a C×R matrix where element `[i][j]` in the original becomes element `[j][i]` in the result.

## Brute Force Approach

There isn't a separate "brute force" here — transposing a matrix is inherently a single pass over every cell. The approach below **is** the direct, optimal solution; there's no redundant work to eliminate.

## Optimal Approach: Direct Index Swap

**Idea:** Allocate a new C×R matrix, then copy every element from its original position to its swapped position.

**Algorithm:**
1. Create a result matrix with `C` rows and `R` columns (dimensions swapped from the input).
2. For every `(i, j)` in the original `R × C` matrix: `result[j][i] = matrix[i][j]`.
3. Return the result.

**Why This Works:** Transposition is defined exactly as "swap row and column indices" — there's no computation involved beyond the index swap itself, so a single pass that visits every cell once and writes it to its mirrored position is both correct and optimal by construction.

**Complexity Analysis:**
- **Time:** O(R × C) — every cell is visited exactly once.
- **Space:** O(R × C) for the new result matrix (this problem returns a new matrix rather than transposing in place, which also sidesteps the extra complexity of in-place transposition for non-square matrices).

### Edge Cases to Consider

- **1×1 matrix**: transposing a single element returns that same element unchanged, just still wrapped as a 1×1 matrix.
- **Row vector (1×C) or column vector (R×1)**: transposes into the other shape entirely (a single row becomes a single column, and vice versa) — the general algorithm handles this with no special-casing, since it's just the `R=1` or `C=1` case of the same index swap.
- **Square matrix**: the transpose reflects every element across the main diagonal; elements *on* the diagonal (`matrix[i][i]`) stay in place.
- **Symmetric matrix** (e.g. a matrix that already equals its own transpose): the output is identical to the input — a useful property to notice, though the algorithm doesn't need to detect or special-case it.

def transpose_matrix(matrix: list) -> list:
    rows, cols = len(matrix), len(matrix[0])

## Key Takeaways

- Transposition is a pure index swap — `result[j][i] = matrix[i][j]` for every cell — with no computation beyond that, making the direct approach both the simplest and the optimal one.
- Always allocate the result with the *swapped* dimensions (`C × R`, not `R × C`) before writing into it — this is the detail most likely to be gotten backwards.
- The algorithm needs no special-casing for row vectors, column vectors, single elements, or square matrices — all of them fall out correctly from the same general double loop.
