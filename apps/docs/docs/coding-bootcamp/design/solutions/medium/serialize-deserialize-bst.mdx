# Serialize and Deserialize BST — Solution

## Problem Overview

Design `serialize`/`deserialize` functions for a Binary Search Tree — encode a tree to a string, then reconstruct the exact same tree from that string.

## Brute Force Approach

**Idea:** Serialize using a level-order traversal with explicit null markers (the same format used for building a tree from an array elsewhere in this course), then deserialize by rebuilding level by level. This works for *any* binary tree, not just a BST, but it's more verbose than necessary — it doesn't take advantage of the BST ordering property at all.

**Complexity Analysis:**
- **Time:** O(n) for both directions.
- **Space:** O(n) for the serialized string, which includes explicit null markers for every missing child.

## Optimal Approach: Preorder Traversal + BST Bounds Reconstruction

**Idea:** For a *binary search tree* specifically, a plain preorder traversal (no null markers needed at all) already uniquely determines the tree — this is the same property the "Construct BST from Preorder Traversal" problem is built on. Serialize by writing out the preorder sequence; deserialize by replaying that same "each value implies a valid range for the rest of its subtree" reconstruction.

**Algorithm — `serialize`:**
1. Walk the tree in preorder (root, then left subtree, then right subtree), collecting each node's value.
2. Join the collected values into a single space-separated string.

**Algorithm — `deserialize`:**
1. Split the string back into a list of values, and keep a shared index pointing at the next unconsumed value.
2. Recursively build a subtree given an upper bound: if the index has run out, or the next value exceeds the bound, this subtree is empty — return `null`/`None`.
3. Otherwise, consume the next value as this subtree's root, recursively build its left child (passing the root's own value as the new upper bound — a BST's left subtree is bounded above by its parent), then recursively build its right child (passing the *same* bound the current call received).

**Why This Works:** In a preorder traversal, once you've placed a node, every subsequent value that's still less than it must belong to its left subtree (by the BST property) — and the moment a value exceeds it, the left subtree is finished and everything from there is either this node's right subtree or an ancestor's. Tracking a single shrinking upper bound as you recurse is exactly what distinguishes "still part of this subtree" from "belongs higher up," with no null markers ever needed.

**Complexity Analysis:**
- **Time:** O(n) for both `serialize` and `deserialize` — each node is visited exactly once in each direction.
- **Space:** O(n) for the serialized string and the reconstructed tree; O(h) recursion depth.

## Deep Dive

### Visual Walkthrough

Serializing then deserializing the tree with preorder `[4, 2, 1, 3, 6, 5, 7]`:

```
Serialize: preorder walk visits 4, 2, 1, 3, 6, 5, 7 in that order
  -> "4 2 1 3 6 5 7"

Deserialize (bound starts at +infinity):
  build(bound=+inf): next=4, within bound -> root=4, consume
    left  = build(bound=4):  next=2, 2<=4 -> node=2, consume
      left  = build(bound=2): next=1, 1<=2 -> node=1, consume
        left  = build(bound=1): next=3, 3>1 -> None (3 doesn't belong here)
        right = build(bound=2): next=3, 3>2 -> None (still doesn't fit under 2's bound)
      right = build(bound=4): next=3, 3<=4 -> node=3, consume
        left/right: index exhausted or next value (6) > 4 -> both None
    right = build(bound=+inf): next=6, fits -> root's right child=6, consume
      ... continues similarly for 5 and 7

Reconstructed tree's own preorder: 4 2 1 3 6 5 7 -- matches the original
```

### Edge Cases to Consider

- **Single-node tree**: `serialize` produces just that one value; `deserialize` consumes it as the root with no further recursion needed (the index immediately runs out).
- **Fully right-leaning chain** (e.g. preorder `2 3` — every value bigger than the last): every `build` call for a left child immediately sees a value exceeding its bound and returns `None`, while the right-child calls keep consuming — the reconstruction naturally produces a chain, not a balanced tree.
- **Fully left-leaning chain** (e.g. preorder `3 1 2`... wait, this one interleaves — the point is any shape is reconstructed correctly since the bound-tracking works identically regardless of tree shape.
- **The upper bound never actually needs a real "infinity" sentinel value in most languages** — using the language's actual maximum representable integer works fine as a stand-in, since node values are constrained well below it.

def serialize(root):
    """Encodes a BST to a single string."""
    result = []
    def preorder(node):
        if node is None:
            return
        result.append(str(node.val))
        preorder(node.left)
        preorder(node.right)
    preorder(root)
    return ' '.join(result)

def deserialize(data):
    """Decodes your encoded data to tree."""
    if not data:
        return None
    tokens = list(map(int, data.split()))
    state = {'idx': 0}

    def build(bound):
        if state['idx'] == len(tokens) or tokens[state['idx']] > bound:
            return None
        val = tokens[state['idx']]
        state['idx'] += 1
        node = TreeNode(val)
        node.left = build(val)     # left subtree bounded above by this node's value
        node.right = build(bound)  # right subtree keeps the same bound as this call
        return node

    return build(float('inf'))

class Codec {
    // Encodes a tree to a single string.
    public String serialize(TreeNode root) {
        StringBuilder sb = new StringBuilder();
        preorder(root, sb);
        return sb.toString().trim();
    }

    private void preorder(TreeNode node, StringBuilder sb) {
        if (node == null) return;
        if (sb.length() > 0) sb.append(' ');
        sb.append(node.val);
        preorder(node.left, sb);
        preorder(node.right, sb);
    }

    // Decodes your encoded data to tree.
    private int idx;
    private int[] tokens;

    public TreeNode deserialize(String data) {
        if (data.isEmpty()) return null;
        String[] parts = data.split(" ");
        tokens = new int[parts.length];
        for (int i = 0; i < parts.length; i++) tokens[i] = Integer.parseInt(parts[i]);
        idx = 0;
        return build(Integer.MAX_VALUE);
    }

    private TreeNode build(int bound) {
        if (idx == tokens.length || tokens[idx] > bound) return null;
        int val = tokens[idx++];
        TreeNode node = new TreeNode(val);
        node.left = build(val);      // left subtree bounded above by this node's value
        node.right = build(bound);   // right subtree keeps the same bound as this call
        return node;
    }
}

fn serialize(root: Option<Rc<RefCell<TreeNode>>>) -> String {
    let mut result: Vec<String> = Vec::new();

    fn preorder(node: &Option<Rc<RefCell<TreeNode>>>, out: &mut Vec<String>) {
        if let Some(n) = node {
            out.push(n.borrow().val.to_string());
            preorder(&n.borrow().left.clone(), out);
            preorder(&n.borrow().right.clone(), out);
        }
    }

    preorder(&root, &mut result);
    result.join(" ")
}

fn deserialize(data: String) -> Option<Rc<RefCell<TreeNode>>> {
    if data.is_empty() {
        return None;
    }
    let tokens: Vec<i32> = data.split_whitespace().map(|s| s.parse().unwrap()).collect();
    let mut idx = 0;

    fn build(tokens: &[i32], idx: &mut usize, bound: i32) -> Option<Rc<RefCell<TreeNode>>> {
        if *idx == tokens.len() || tokens[*idx] > bound {
            return None;
        }
        let val = tokens[*idx];
        *idx += 1;
        let node = TreeNode::new(val);
        let left = build(tokens, idx, val);      // left subtree bounded above by this node's value
        let right = build(tokens, idx, bound);   // right subtree keeps the same bound as this call
        node.borrow_mut().left = left;
        node.borrow_mut().right = right;
        Some(node)
    }

    build(&tokens, &mut idx, std::i32::MAX)
}

    if (!node) return;

    preorderStr(node->left, buf);

static int g_idx;

static struct TreeNode* build(int bound) {
    if (g_idx == g_count || g_tokens[g_idx] > bound) return NULL;

    struct TreeNode* node = (struct TreeNode*)malloc(sizeof(struct TreeNode));
    node->val = val;

    node->right = build(bound);  // right subtree keeps the same bound as this call

struct TreeNode* deserialize(char* data) {
    if (data == NULL || data[0] == '\0') return NULL;
    g_count = 0;
    char* p = data;
    while (sscanf(p, "%d", &g_tokens[g_count]) == 1) {
        g_count++;
        while (*p && *p != ' ') p++;
        while (*p == ' ') p++;
    }
    g_idx = 0;
    return build(2147483647);
}

    public string serialize(TreeNode root) {

        Preorder(root, result);
        return string.Join(" ", result);
    }

    private void Preorder(TreeNode node, List<string> result) {
        if (node == null) return;
        result.Add(node.val.ToString());
        Preorder(node.left, result);
        Preorder(node.right, result);

    private int idx;

func serialize(root *TreeNode) string {
    var parts []string
    var preorder func(node *TreeNode)
    preorder = func(node *TreeNode) {
        if node == nil {
            return
        }
        parts = append(parts, strconv.Itoa(node.Val))
        preorder(node.Left)
        preorder(node.Right)
    }
    preorder(root)
    return strings.Join(parts, " ")
}

func deserialize(data string) *TreeNode {
    if data == "" {
        return nil
    }
    parts := strings.Fields(data)
    tokens := make([]int, len(parts))
    for i, p := range parts {
        tokens[i], _ = strconv.Atoi(p)
    }
    idx := 0
    var build func(bound int) *TreeNode
    build = func(bound int) *TreeNode {
        if idx == len(tokens) || tokens[idx] > bound {
            return nil
        }
        val := tokens[idx]
        idx++
        node := &TreeNode{Val: val}
        node.Left = build(val)     // left subtree bounded above by this node's value
        node.Right = build(bound)  // right subtree keeps the same bound as this call
        return node
    }
    return build(math.MaxInt32)
}

## Key Takeaways

- A binary search tree's preorder traversal alone (no null markers) is enough to uniquely reconstruct it — this is a strictly more compact encoding than the level-order-with-nulls format needed for a *general* binary tree.
- The reconstruction trick is tracking a single shrinking upper bound as recursion descends: a node's left subtree is bounded above by the node's own value, while its right subtree inherits whatever bound the node itself was given.
- This is the same core algorithm as "Construct BST from Preorder Traversal" — recognizing that a serialize/deserialize problem for a BST reduces to a traversal-and-reconstruction problem you may have already solved is a useful pattern-matching habit.
