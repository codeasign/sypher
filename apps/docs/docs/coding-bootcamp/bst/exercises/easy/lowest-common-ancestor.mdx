# Lowest Common Ancestor of a BST

**Difficulty:** Easy

Given the `root` of a **binary search tree**, and two integers `p` and `q` representing values that both exist in the tree, find the value of their **lowest common ancestor (LCA)**.

The lowest common ancestor of two nodes `p` and `q` is defined as the lowest (deepest) node in the tree that has both `p` and `q` as descendants (a node is allowed to be a descendant of itself).

## Example 1

**Input:**
```
11
6 2 8 0 4 7 9 -1 -1 3 5
2 8
```

The tree is:
```
        6
      /   \
     2     8
    / \   / \
   0   4 7   9
      / \
     3   5
```

**Output:** `6`
**Explanation:** `2` and `8` are on opposite sides of the root, so the root itself is their lowest common ancestor.

## Example 2

**Input:**
```
11
6 2 8 0 4 7 9 -1 -1 3 5
2 4
```

**Output:** `2`
**Explanation:** Node `2` is itself an ancestor of node `4` (its right child), so `2` is the LCA.

## Example 3

**Input:**
```
11
6 2 8 0 4 7 9 -1 -1 3 5
3 5
```

**Output:** `4`
**Explanation:** `3` and `5` are both children of `4`, so `4` is their LCA.

## Input Specification

- First line: an integer `n` — number of nodes in the tree (`1 <= n <= 10^4`)
- Second line (only present when `n > 0`): `n` space-separated integers representing the level-order traversal of the tree (use `-1` for null nodes)
- Third line: two space-separated integers `p q` — values guaranteed to exist in the tree (all node values are distinct)

## Output Specification

Print the value of the lowest common ancestor of `p` and `q`.

## Constraints

- The number of nodes is in the range `[1, 10^4]`
- `-10^9 <= Node.val <= 10^9`
- All node values are unique
- `p` and `q` both exist in the tree, and `p != q` unless the tree has only one node

## Hints

<details>
<summary>Hint 1</summary>

This is a **binary search tree**, not just a binary tree — you don't need general tree-LCA techniques. The BST ordering property alone tells you which direction to go at every step.
</details>

<details>
<summary>Hint 2</summary>

Starting at the root, compare both `p` and `q` to the current node's value. If both are smaller, the LCA must be in the left subtree — move left. If both are larger, move right. The moment they're no longer both on the same side (one is smaller, one is larger, or one equals the current node), the current node is the LCA.
</details>

<details>
<summary>Hint 3</summary>

This can be done iteratively with a simple `while` loop walking down from the root — no recursion, extra stack, or parent pointers needed.
</details>
