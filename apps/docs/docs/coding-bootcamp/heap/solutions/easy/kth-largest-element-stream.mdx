# Kth Largest Element in a Stream — Solution

## Approach: Min-Heap of Size k

**Algorithm:** Maintain a min-heap of size k. The smallest element is the kth largest. When adding, push then pop if size > k.

**Complexity:** O(n log k) time, O(k) space.

## Code

```python
import heapq

class KthLargest:
    def __init__(self, k: int, nums: list[int]):
        self.k = k
        self.heap = []
        for val in nums:
            self.add(val)  # Reuse add logic

    def add(self, val: int) -> int:
        heapq.heappush(self.heap, val)
        if len(self.heap) > self.k:
            heapq.heappop(self.heap)
        return self.heap[0]  # kth largest is the smallest in heap
```

```javascript
class KthLargest {
    constructor(k, nums) {
        this.k = k;
        this.heap = []; // kept sorted ascending; heap[0] is the smallest (kth largest)
        for (const val of nums) {
            this.add(val);
        }
    }

    add(val) {
        // Insert into sorted position (ascending)
        let lo = 0, hi = this.heap.length;
        while (lo < hi) {
            const mid = (lo + hi) >> 1;
            if (this.heap[mid] < val) lo = mid + 1;
            else hi = mid;
        }
        this.heap.splice(lo, 0, val);
        if (this.heap.length > this.k) {
            this.heap.shift(); // evict the smallest once size exceeds k
        }
        return this.heap[0];
    }
}
```
