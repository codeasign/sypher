# Angle Between Hands of a Clock

**Difficulty:** Medium

Given two numbers, `hour` and `minutes`, representing the time shown on a 12-hour analog clock, return the **smaller angle** (in degrees) formed between the hour hand and the minute hand.

Answer within `10^-5` of the actual value is considered accepted, but this course grades on an exact string match — every solution here prints the result rounded to exactly one decimal place, so the two things to get right are the angle formula and the `.5`/`.0` step of the answer, not floating-point precision.

## Example 1

**Input:** `hour = 12, minutes = 30`
**Output:** `165.0`
**Explanation:** At 12:30, the hour hand has moved a quarter of the way from the 12 to the 1 (since 30 minutes is half an hour), landing at 15°. The minute hand, at the 6, is at 180°. The angle between them is `|180 - 15| = 165`, and `165` is already the smaller of `165` and `360 - 165 = 195`.

## Example 2

**Input:** `hour = 3, minutes = 30`
**Output:** `75.0`

## Example 3

**Input:** `hour = 12, minutes = 45`
**Output:** `112.5`
**Explanation:** The minute hand is at `45 * 6 = 270`°. The hour hand is at `45 * 0.5 = 22.5`° (past 12). The raw difference is `247.5`, but the smaller angle going the other way around the clock face is `360 - 247.5 = 112.5`.

## Input Specification

- One line: two space-separated integers `hour minutes`.
- `1 <= hour <= 12`
- `0 <= minutes <= 59`

## Output Specification

Print the smaller angle between the two hands, in degrees, formatted to exactly one decimal place.

## Constraints

- `1 <= hour <= 12`
- `0 <= minutes <= 59`
- Answers are always a multiple of `0.5` degrees, so one decimal place is always exact — never rounded.

## Hints

<details>
<summary>Hint 1</summary>

The minute hand moves 360° in 60 minutes, so it moves `6°` per minute: `minute_angle = minutes * 6`.
</details>

<details>
<summary>Hint 2</summary>

The hour hand moves 360° in 12 hours (`30°` per hour), but it also creeps forward as the minutes pass within the current hour — an extra `0.5°` per minute (`30° / 60`). So `hour_angle = (hour % 12) * 30 + minutes * 0.5`. Don't forget the `% 12` — `hour = 12` should behave like `hour = 0` for this formula.
</details>

<details>
<summary>Hint 3</summary>

Take the absolute difference between the two angles, then return whichever is smaller: that difference, or `360` minus that difference (since the two hands also form an angle going the "other way around" the clock face).
</details>
