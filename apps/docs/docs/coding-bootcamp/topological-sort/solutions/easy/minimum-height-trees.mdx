# Minimum Height Trees — Solution

## Problem Overview

Given an undirected tree, find every node that, when chosen as the root, minimizes the tree's height (the longest downward path from root to leaf).

## Brute Force Approach

**Idea:** For every candidate root, run a BFS/DFS from it to compute the tree's height when rooted there, then keep whichever root(s) achieve the minimum.

**Complexity Analysis:**
- **Time:** O(n²) — one O(n) traversal per candidate root, across n candidates.
- **Space:** O(n) for the adjacency list and BFS queue.

## Optimal Approach: Peel Leaves Layer by Layer (Topological Trim)

**Idea:** The node(s) that minimize height are always the tree's **centroid** (at most 2 of them, adjacent to each other if there are 2) — the node(s) left standing after repeatedly stripping away the tree's outermost layer of leaves. This is structurally identical to Kahn's algorithm for topological sort: instead of peeling nodes with in-degree 0, peel nodes with degree 1 (leaves), layer by layer, until 1 or 2 nodes remain.

**Algorithm:**
1. Special-case `n == 1`: the single node is its own answer.
2. Build an adjacency list and compute each node's degree.
3. Seed a queue with every node of degree 1 (the initial leaves).
4. While more than 2 nodes remain: remove the current layer of leaves, decrementing the degree of each of their neighbors. Any neighbor whose degree drops to 1 becomes part of the next layer.
5. The 1 or 2 nodes left when the loop stops are the answer.

**Why This Works:** Peeling the outermost leaves is equivalent to shrinking the tree inward from every direction simultaneously, one unit of eccentricity at a time. The last node(s) standing are exactly the node(s) with minimum eccentricity — the graph-theoretic centroid — which is precisely the set of roots that minimizes height. A tree's centroid is always 1 or 2 nodes (never more), so the loop naturally terminates with the correct-size answer.

**Complexity Analysis:**
- **Time:** O(n) — every node and edge is visited a constant number of times across the whole peeling process (this is exactly Kahn's algorithm, just peeling on degree instead of in-degree).
- **Space:** O(n) for the adjacency list, degree array, and queue.

## Deep Dive

### Visual Walkthrough

For `n = 6`, edges `[[3,0],[3,1],[3,2],[3,4],[4,5]]`:

```
    0   1   2
     \  |  /
      \ | /
        3
        |
        4
        |
        5
```

- Initial leaves (degree 1): `0, 1, 2, 5`. Remaining: 6.
- Peel layer 1: remove `0, 1, 2, 5`. Node `3` drops from degree 4 to degree 1 (becomes a leaf). Node `4` drops from degree 2 to degree 1 (becomes a leaf). Remaining: 2.
- Loop stops (remaining == 2). Answer: `[3, 4]`.

### Edge Cases to Consider

- **`n == 1`**: there are no edges at all — the single node has degree 0, never enters the leaf queue, so it must be special-cased and returned directly as `[0]`.
- **`n == 2`**: both nodes have degree 1 and are leaves from the start — the loop condition (`remaining > 2`) is already false, so both are immediately returned as `[0, 1]`, correctly reflecting that either endpoint of a single edge gives the same (minimal) height.
- **A straight-line path** (e.g. `0-1-2-3-4-5-6`): the peeling proceeds symmetrically inward from both ends, converging on the path's middle node (odd length) or middle two nodes (even length) — exactly matching the intuitive "center of a line" answer.
- **A perfectly balanced tree**: only the true structural root survives peeling, since every other node's subtree is asymmetric relative to it and yields a strictly taller rooting.
- **A "star with one long tail"** (a hub node with several short branches and one long one): the peeling naturally favors the node(s) that balance the longest remaining branch against the rest, which is not always the highest-degree hub — ties between two adjacent nodes are common in this shape and both must be reported.

from collections import deque

def find_min_height_trees(n: int, edges: list) -> list:
    if n == 1:
        return [0]

    adj = [set() for _ in range(n)]
    for u, v in edges:
        adj[u].add(v)
        adj[v].add(u)

    leaves = deque([i for i in range(n) if len(adj[i]) == 1])
    remaining = n
    while remaining > 2:
        layer_size = len(leaves)
        remaining -= layer_size
        for _ in range(layer_size):
            leaf = leaves.popleft()
            for neighbor in adj[leaf]:
                adj[neighbor].discard(leaf)
                if len(adj[neighbor]) == 1:
                    leaves.append(neighbor)

    return sorted(leaves)

class Solution {
    public List<Integer> findMinHeightTrees(int n, int[][] edges) {
        List<Integer> result = new ArrayList<>();
        if (n == 1) {
            result.add(0);
            return result;
        }

        List<Set<Integer>> adj = new ArrayList<>();
        for (int i = 0; i < n; i++) adj.add(new HashSet<>());
        for (int[] edge : edges) {
            adj.get(edge[0]).add(edge[1]);
            adj.get(edge[1]).add(edge[0]);
        }

        Queue<Integer> leaves = new LinkedList<>();
        for (int i = 0; i < n; i++) {
            if (adj.get(i).size() == 1) leaves.add(i);
        }

        int remaining = n;
        while (remaining > 2) {
            int layerSize = leaves.size();
            remaining -= layerSize;
            for (int i = 0; i < layerSize; i++) {
                int leaf = leaves.poll();
                for (int neighbor : adj.get(leaf)) {
                    adj.get(neighbor).remove(leaf);
                    if (adj.get(neighbor).size() == 1) leaves.add(neighbor);
                }
            }
        }

        result.addAll(leaves);
        Collections.sort(result);
        return result;
    }
}

class Solution {
public:
    vector<int> findMinHeightTrees(int n, vector<vector<int>>& edges) {
        if (n == 1) return {0};

        vector<unordered_set<int>> adj(n);
        for (auto& e : edges) {
            adj[e[0]].insert(e[1]);
            adj[e[1]].insert(e[0]);
        }

        queue<int> leaves;
        for (int i = 0; i < n; i++) {
            if (adj[i].size() == 1) leaves.push(i);
        }

        int remaining = n;
        while (remaining > 2) {
            int layerSize = leaves.size();
            remaining -= layerSize;
            for (int i = 0; i < layerSize; i++) {
                int leaf = leaves.front();
                leaves.pop();
                for (int neighbor : adj[leaf]) {
                    adj[neighbor].erase(leaf);
                    if (adj[neighbor].size() == 1) leaves.push(neighbor);
                }
            }
        }

        vector<int> result;
        while (!leaves.empty()) {
            result.push_back(leaves.front());
            leaves.pop();
        }
        sort(result.begin(), result.end());
        return result;
    }
};

use std::collections::{HashSet, VecDeque};

fn find_min_height_trees(n: i32, edges: Vec<Vec<i32>>) -> Vec<i32> {
    if n == 1 {
        return vec![0];
    }
    let n = n as usize;

    let mut adj: Vec<HashSet<usize>> = vec![HashSet::new(); n];
    for e in &edges {
        let u = e[0] as usize;
        let v = e[1] as usize;
        adj[u].insert(v);
        adj[v].insert(u);
    }

    let mut leaves: VecDeque<usize> = VecDeque::new();
    for i in 0..n {
        if adj[i].len() == 1 {
            leaves.push_back(i);
        }
    }

    let mut remaining = n;
    while remaining > 2 {
        let layer_size = leaves.len();
        remaining -= layer_size;
        for _ in 0..layer_size {
            let leaf = leaves.pop_front().unwrap();
            let neighbors: Vec<usize> = adj[leaf].iter().cloned().collect();
            for neighbor in neighbors {
                adj[neighbor].remove(&leaf);
                if adj[neighbor].len() == 1 {
                    leaves.push_back(neighbor);
                }
            }
        }
    }

    let mut result: Vec<i32> = leaves.iter().map(|&x| x as i32).collect();
    result.sort();
    result
}

int* findMinHeightTrees(int n, int** edges, int edgesSize, int* edgesColSize, int* returnSize) {
    if (n == 1) {
        int* result = (int*)malloc(sizeof(int));
        result[0] = 0;
        *returnSize = 1;
        return result;
    }

    int* degree = (int*)calloc(n, sizeof(int));
    int* adjHead = (int*)malloc(n * sizeof(int));
    for (int i = 0; i < n; i++) adjHead[i] = -1;
    int* adjNext = (int*)malloc(2 * edgesSize * sizeof(int));
    int* adjTo = (int*)malloc(2 * edgesSize * sizeof(int));
    int edgeCount = 0;

    for (int i = 0; i < edgesSize; i++) {
        int u = edges[i][0], v = edges[i][1];
        adjTo[edgeCount] = v; adjNext[edgeCount] = adjHead[u]; adjHead[u] = edgeCount++;
        adjTo[edgeCount] = u; adjNext[edgeCount] = adjHead[v]; adjHead[v] = edgeCount++;
        degree[u]++;
        degree[v]++;
    }

    int* removed = (int*)calloc(n, sizeof(int));
    int* queue = (int*)malloc(n * sizeof(int));
    int qHead = 0, qTail = 0;
    for (int i = 0; i < n; i++) {
        if (degree[i] == 1) queue[qTail++] = i;
    }

    int remaining = n;
    while (remaining > 2) {
        int layerSize = qTail - qHead;
        remaining -= layerSize;
        for (int i = 0; i < layerSize; i++) {
            int leaf = queue[qHead++];
            removed[leaf] = 1;
            for (int e = adjHead[leaf]; e != -1; e = adjNext[e]) {
                int neighbor = adjTo[e];
                if (!removed[neighbor]) {
                    degree[neighbor]--;
                    if (degree[neighbor] == 1) queue[qTail++] = neighbor;
                }
            }
        }
    }

    int count = qTail - qHead;
    int* result = (int*)malloc(count * sizeof(int));
    for (int i = 0; i < count; i++) result[i] = queue[qHead + i];
    for (int i = 0; i < count - 1; i++)
        for (int j = i + 1; j < count; j++)
            if (result[i] > result[j]) { int tmp = result[i]; result[i] = result[j]; result[j] = tmp; }
    *returnSize = count;
    return result;
}

class Solution {
    public IList<int> FindMinHeightTrees(int n, int[][] edges) {
        if (n == 1) return new List<int> { 0 };

        var adj = new List<HashSet<int>>();
        for (int i = 0; i < n; i++) adj.Add(new HashSet<int>());
        foreach (var e in edges) {
            adj[e[0]].Add(e[1]);
            adj[e[1]].Add(e[0]);
        }

        var leaves = new Queue<int>();
        for (int i = 0; i < n; i++) {
            if (adj[i].Count == 1) leaves.Enqueue(i);
        }

        int remaining = n;
        while (remaining > 2) {
            int layerSize = leaves.Count;
            remaining -= layerSize;
            for (int i = 0; i < layerSize; i++) {
                int leaf = leaves.Dequeue();
                foreach (int neighbor in adj[leaf]) {
                    adj[neighbor].Remove(leaf);
                    if (adj[neighbor].Count == 1) leaves.Enqueue(neighbor);
                }
            }
        }

        var result = leaves.ToList();
        result.Sort();
        return result;
    }
}

func findMinHeightTrees(n int, edges [][]int) []int {
    if n == 1 {
        return []int{0}
    }

    adj := make([]map[int]bool, n)
    for i := range adj {
        adj[i] = make(map[int]bool)
    }
    for _, e := range edges {
        adj[e[0]][e[1]] = true
        adj[e[1]][e[0]] = true
    }

    var leaves []int
    for i := 0; i < n; i++ {
        if len(adj[i]) == 1 {
            leaves = append(leaves, i)
        }
    }

    remaining := n
    for remaining > 2 {
        var next []int
        remaining -= len(leaves)
        for _, leaf := range leaves {
            for neighbor := range adj[leaf] {
                delete(adj[neighbor], leaf)
                if len(adj[neighbor]) == 1 {
                    next = append(next, neighbor)
                }
            }
        }
        leaves = next
    }

    sort.Ints(leaves)
    return leaves
}

## Key Takeaways

- A tree's minimum-height root(s) are exactly its centroid — at most 2 nodes, found by repeatedly peeling the outermost layer of leaves, structurally identical to Kahn's topological-sort algorithm run on degree instead of in-degree.
- This turns an O(n²) brute-force (BFS from every candidate root) into a single O(n) pass, since each node/edge is only ever touched a constant number of times during peeling.
- `n == 1` has to be special-cased — with zero edges, the lone node never reaches degree 1 and would never enter the leaf queue otherwise.
