# Sequence Reconstruction — Solution

## Problem Overview

Given a permutation `org` and a list of subsequences `seqs`, determine whether `org` is the **unique** shortest common supersequence of `seqs` — meaning the ordering constraints implied by `seqs` pin down exactly one valid arrangement, and it happens to be `org`.

## Brute Force Approach

**Idea:** Generate every permutation of `1..n`, check which ones are valid supersequences of every sequence in `seqs`, and see whether `org` is the only one.

**Complexity Analysis:**
- **Time:** O(n! × n × k) — factorial blowup, hopelessly impractical beyond tiny `n`.
- **Space:** O(n) per permutation under consideration.

## Optimal Approach: Kahn's Algorithm with a Uniqueness Check

**Idea:** Every consecutive pair within a single sequence in `seqs` is a hard ordering constraint: that first element must come before that second element in any valid supersequence. Treat every such pair as a directed edge and run topological sort (Kahn's algorithm) over the resulting graph. The reconstruction is unique **if and only if**, at every step of the algorithm, there is exactly one node with in-degree 0 available to place next — any point where two or more nodes are simultaneously "ready" means their relative order is ambiguous, and `org` cannot be the *only* valid arrangement.

**Algorithm:**
1. Build a directed graph over the values `1..n`: for every sequence in `seqs`, add an edge from each element to the one immediately following it.
2. Compute in-degree for every node.
3. Seed a queue with all in-degree-0 nodes.
4. Run Kahn's algorithm, but at each step: if the queue ever holds more than one node, the ordering is ambiguous — return `false` immediately.
5. Otherwise, dequeue the single node, append it to the reconstructed order, and decrement its neighbors' in-degrees (enqueuing any that drop to 0).
6. After the algorithm completes, return `true` only if the reconstructed order has length `n` and equals `org` exactly.

**Why This Works:** A topological sort's *set* of valid orderings is unique precisely when no two "ready" nodes ever compete for the same position — that's the textbook characterization of a DAG having a single valid topological order. Checking `queue.length > 1` at every step is exactly that characterization applied incrementally. Any node from `org` that never appears in any edge stays at in-degree 0 indefinitely, which surfaces as exactly this kind of tie the moment another node is also ready — so an "uncovered" node is automatically caught by the same check, no special-casing needed.

**Complexity Analysis:**
- **Time:** O(n + sum of len(seqs[i])) — building the graph and running Kahn's algorithm are both linear in the total input size.
- **Space:** O(n + edges) for the adjacency structure and in-degree array.

### Edge Cases to Consider

- **A value in `org` that never appears in any sequence**: it starts at in-degree 0 and stays there — the moment any other node is also ready (which, for `n > 1`, is essentially guaranteed), the queue's size check catches the tie and correctly returns `false`. No separate "was this value ever seen" bookkeeping is needed.
- **`k == 0` (no sequences at all) with `n > 1`**: every node starts at in-degree 0 simultaneously, so the very first queue check already has more than one candidate — correctly `false`.
- **A single-element `org`** (`n == 1`): trivially `true` regardless of `seqs`, since there's nothing to order.
- **A sequence value outside `[1, n]`** (malformed input): defensively reject as `false` immediately rather than letting it corrupt the graph — this course's harnesses always emit well-formed data, but the check costs nothing and matches the problem's own stated contract.
- **A fully-connected chain of edges that exactly reconstructs `org`**: this is the genuinely-unique case and must return `true` — worth double-checking by hand when authoring test data for this problem, since a seemingly "not obviously true" input can turn out to have a single unbroken constraint chain covering every element, which is exactly the unique-reconstruction condition.

from collections import deque

def sequence_reconstruction(org: list, seqs: list) -> bool:
    node_set = set(org)
    adj = {v: set() for v in org}
    indegree = {v: 0 for v in org}

    for seq in seqs:
        for v in seq:
            if v not in node_set:
                return False
        for i in range(len(seq) - 1):
            u, w = seq[i], seq[i + 1]
            if w not in adj[u]:
                adj[u].add(w)
                indegree[w] += 1

    queue = deque([v for v in org if indegree[v] == 0])
    result = []
    while queue:
        if len(queue) > 1:
            return False
        node = queue.popleft()
        result.append(node)
        for nxt in adj[node]:
            indegree[nxt] -= 1
            if indegree[nxt] == 0:
                queue.append(nxt)

    return result == org

class Solution {
    public boolean sequenceReconstruction(int[] org, List<List<Integer>> seqs) {
        Set<Integer> nodeSet = new HashSet<>();
        for (int v : org) nodeSet.add(v);

        Map<Integer, Set<Integer>> adj = new HashMap<>();
        Map<Integer, Integer> indegree = new HashMap<>();
        for (int v : org) {
            adj.put(v, new HashSet<>());
            indegree.put(v, 0);
        }

        for (List<Integer> seq : seqs) {
            for (int v : seq) {
                if (!nodeSet.contains(v)) return false;
            }
            for (int i = 0; i < seq.size() - 1; i++) {
                int u = seq.get(i), w = seq.get(i + 1);
                if (adj.get(u).add(w)) {
                    indegree.put(w, indegree.get(w) + 1);
                }
            }
        }

        Queue<Integer> queue = new LinkedList<>();
        for (int v : org) {
            if (indegree.get(v) == 0) queue.add(v);
        }

        List<Integer> result = new ArrayList<>();
        while (!queue.isEmpty()) {
            if (queue.size() > 1) return false;
            int node = queue.poll();
            result.add(node);
            for (int nxt : adj.get(node)) {
                indegree.put(nxt, indegree.get(nxt) - 1);
                if (indegree.get(nxt) == 0) queue.add(nxt);
            }
        }

        if (result.size() != org.length) return false;
        for (int i = 0; i < org.length; i++) {
            if (!result.get(i).equals(org[i])) return false;
        }
        return true;
    }
}

public:
    bool sequenceReconstruction(vector<int>& org, vector<vector<int>>& seqs) {
        unordered_set<int> nodeSet(org.begin(), org.end());
        unordered_map<int, unordered_set<int>> adj;
        unordered_map<int, int> indegree;

            indegree[v] = 0;

            for (int v : seq) {
                if (nodeSet.find(v) == nodeSet.end()) return false;
            }
            for (size_t i = 0; i + 1 < seq.size(); i++) {
                int u = seq[i], w = seq[i + 1];
                if (adj[u].insert(w).second) {
                    indegree[w]++;
                }
            }
        }

        queue<int> q;
        for (int v : org) {
            if (indegree[v] == 0) q.push(v);
        }

        vector<int> result;
        while (!q.empty()) {
            if (q.size() > 1) return false;
            int node = q.front();
            q.pop();
            result.push_back(node);
            for (int nxt : adj[node]) {
                if (--indegree[nxt] == 0) q.push(nxt);
            }
        }

        return result == org;
    }

use std::collections::{HashMap, HashSet, VecDeque};

fn sequence_reconstruction(org: Vec<i32>, seqs: Vec<Vec<i32>>) -> bool {
    let node_set: HashSet<i32> = org.iter().cloned().collect();
    let mut adj: HashMap<i32, HashSet<i32>> = HashMap::new();
    let mut indegree: HashMap<i32, i32> = HashMap::new();
    for &v in &org {
        adj.insert(v, HashSet::new());
        indegree.insert(v, 0);
    }

    for seq in &seqs {
        for &v in seq {
            if !node_set.contains(&v) {
                return false;
            }
        }
        for i in 0..seq.len().saturating_sub(1) {
            let u = seq[i];
            let w = seq[i + 1];
            if adj.get_mut(&u).unwrap().insert(w) {
                *indegree.get_mut(&w).unwrap() += 1;
            }
        }
    }

    let mut queue: VecDeque<i32> = org.iter()
        .filter(|v| indegree[v] == 0)
        .cloned()
        .collect();

    let mut result: Vec<i32> = Vec::new();
    while !queue.is_empty() {
        if queue.len() > 1 {
            return false;
        }
        let node = queue.pop_front().unwrap();
        result.push(node);
        let neighbors: Vec<i32> = adj[&node].iter().cloned().collect();
        for nxt in neighbors {
            let d = indegree.get_mut(&nxt).unwrap();
            *d -= 1;
            if *d == 0 {
                queue.push_back(nxt);
            }
        }
    }

    result == org
}

bool sequenceReconstruction(int* org, int orgSize, int** seqs, int seqsSize, int* seqsColSize) {
    int maxVal = 0;
    for (int i = 0; i < orgSize; i++) if (org[i] > maxVal) maxVal = org[i];

    int* position = (int*)malloc((maxVal + 1) * sizeof(int));
    for (int i = 0; i <= maxVal; i++) position[i] = -1;
    for (int i = 0; i < orgSize; i++) position[org[i]] = i;

    int* indegree = (int*)calloc(maxVal + 1, sizeof(int));
    unsigned char* adjMatrix = (unsigned char*)calloc((size_t)(maxVal + 1) * (maxVal + 1), 1);

    for (int i = 0; i < seqsSize; i++) {
        for (int j = 0; j < seqsColSize[i]; j++) {
            int v = seqs[i][j];
            if (v < 0 || v > maxVal || position[v] == -1) {
                free(position); free(indegree); free(adjMatrix);
                return false;
            }
        }
        for (int j = 0; j + 1 < seqsColSize[i]; j++) {
            int u = seqs[i][j], w = seqs[i][j + 1];
            size_t idx = (size_t)u * (maxVal + 1) + w;
            if (!adjMatrix[idx]) {
                adjMatrix[idx] = 1;
                indegree[w]++;
            }
        }
    }

    int* queue = (int*)malloc(orgSize * sizeof(int));
    int qHead = 0, qTail = 0;
    for (int i = 0; i < orgSize; i++) {
        if (indegree[org[i]] == 0) queue[qTail++] = org[i];
    }

    int* result = (int*)malloc(orgSize * sizeof(int));
    int resultSize = 0;
    bool ok = true;
    while (qHead < qTail) {
        if (qTail - qHead > 1) { ok = false; break; }
        int node = queue[qHead++];
        result[resultSize++] = node;
        for (int nxt = 0; nxt <= maxVal; nxt++) {
            size_t idx = (size_t)node * (maxVal + 1) + nxt;
            if (adjMatrix[idx]) {
                indegree[nxt]--;
                if (indegree[nxt] == 0) queue[qTail++] = nxt;
            }
        }
    }

    if (ok) {
        if (resultSize != orgSize) ok = false;
        else {
            for (int i = 0; i < orgSize; i++) {
                if (result[i] != org[i]) { ok = false; break; }
            }
        }
    }

    free(position); free(indegree); free(adjMatrix); free(queue); free(result);
    return ok;
}

class Solution {
    public bool SequenceReconstruction(int[] org, IList<IList<int>> seqs) {
        var nodeSet = new HashSet<int>(org);
        var adj = new Dictionary<int, HashSet<int>>();
        var indegree = new Dictionary<int, int>();
        foreach (int v in org) {
            adj[v] = new HashSet<int>();
            indegree[v] = 0;
        }

        foreach (var seq in seqs) {
            foreach (int v in seq) {
                if (!nodeSet.Contains(v)) return false;
            }
            for (int i = 0; i < seq.Count - 1; i++) {
                int u = seq[i], w = seq[i + 1];
                if (adj[u].Add(w)) {
                    indegree[w]++;
                }
            }
        }

        var queue = new Queue<int>();
        foreach (int v in org) {
            if (indegree[v] == 0) queue.Enqueue(v);
        }

        var result = new List<int>();
        while (queue.Count > 0) {
            if (queue.Count > 1) return false;
            int node = queue.Dequeue();
            result.Add(node);
            foreach (int nxt in adj[node]) {
                indegree[nxt]--;
                if (indegree[nxt] == 0) queue.Enqueue(nxt);
            }
        }

        if (result.Count != org.Length) return false;
        for (int i = 0; i < org.Length; i++) {
            if (result[i] != org[i]) return false;
        }
        return true;
    }
}

func sequenceReconstruction(org []int, seqs [][]int) bool {
    nodeSet := make(map[int]bool)
    for _, v := range org {
        nodeSet[v] = true
    }

    adj := make(map[int]map[int]bool)
    indegree := make(map[int]int)
    for _, v := range org {
        adj[v] = make(map[int]bool)
        indegree[v] = 0
    }

    for _, seq := range seqs {
        for _, v := range seq {
            if !nodeSet[v] {
                return false
            }
        }
        for i := 0; i+1 < len(seq); i++ {
            u, w := seq[i], seq[i+1]
            if !adj[u][w] {
                adj[u][w] = true
                indegree[w]++
            }
        }
    }

    var queue []int
    for _, v := range org {
        if indegree[v] == 0 {
            queue = append(queue, v)
        }
    }

    var result []int
    for len(queue) > 0 {
        if len(queue) > 1 {
            return false
        }
        node := queue[0]
        queue = queue[:0]
        result = append(result, node)
        for nxt := range adj[node] {
            indegree[nxt]--
            if indegree[nxt] == 0 {
                queue = append(queue, nxt)
            }
        }
    }

    if len(result) != len(org) {
        return false
    }
    for i := range org {
        if result[i] != org[i] {
            return false
        }
    }
    return true
}

## Key Takeaways

- Uniqueness of a topological order reduces to a single incremental check: does the "ready" queue ever hold more than one node at once? That's the entire difference between this problem and a plain topological-sort existence check.
- A value from `org` that's never mentioned in any sequence doesn't need special-case detection — it simply never accumulates in-degree, so it surfaces as a tie (and therefore `false`) the same way any other ambiguity does.
- When authoring test data for this kind of problem, a chain of edges that happens to cover every element of `org` end-to-end is a *unique* reconstruction (`true`), even if it doesn't look that way at a glance — always trace the actual edge set rather than assuming a "looks incomplete" input is automatically ambiguous.
