Before we write a single type, let's get TypeScript running on your machine. It only takes a couple of minutes, and by the end of this page you'll be able to write a `.ts` file and actually run it.

## Install TypeScript

TypeScript is a language that compiles down to plain JavaScript, so the tool you're installing is really a compiler called `tsc`. You can install it globally, so it's available in every project:

```bash
npm install -g typescript
```

Or, if you'd rather keep it scoped to a single project (a common preference on real teams, since it pins the version per-project):

```bash
npm install --save-dev typescript
```

Either way, check that it worked:

```bash
tsc --version
```

## Create a tsconfig.json

The `tsconfig.json` file tells the compiler how to check and build your code. Instead of writing one by hand, let TypeScript generate it for you:

```bash
tsc --init
```

That command drops a `tsconfig.json` full of options, most of them commented out. You don't need to understand all of them today — here's a trimmed-down version with just the settings worth knowing about right now:

```json
{
  "compilerOptions": {
    "target": "ES2020",
    "module": "commonjs",
    "strict": true,
    "outDir": "dist",
    "rootDir": "src",
    "esModuleInterop": true
  }
}
```

A quick word on each one:

- `target` — which version of JavaScript the compiler outputs. `ES2020` is a safe, modern default.
- `module` — the module system your compiled code uses to import/export files. `commonjs` is the standard choice for running code with Node.
- `strict` — turns on TypeScript's full set of safety checks (things like refusing to let a variable silently be `undefined`). Leave this `true` — it's the whole point of using TypeScript, and it's much easier to start strict than to turn it on later.
- `outDir` — where the compiled `.js` files get written.
- `rootDir` — where your source `.ts` files live.
- `esModuleInterop` — smooths over some quirks with older JavaScript packages so `import` statements just work.

## Running a .ts file

Create a `src` folder with one file in it, `src/index.ts`:

```typescript
const bookTitle: string = "The Midnight Library";
console.log(`Welcome to BookHaven — today's featured book is "${bookTitle}"`);
```

Now compile it and run the result with plain Node:

```bash
tsc
node dist/index.js
```

`tsc` reads your `tsconfig.json`, checks every `.ts` file in `src` for type errors, and — if everything looks good — writes matching `.js` files into `dist`. `node` then runs that plain JavaScript, exactly the way it would run any other Node script. This compile-then-run cycle is what you'll use throughout the course: edit the `.ts` file, run `tsc`, run the output with `node`.

## Meet BookHaven

Throughout this course, every example lives inside **BookHaven**, a small online bookstore — you'll model its books, members, and orders as you learn each new TypeScript feature.

## Try it

Update `src/index.ts` so that, alongside `bookTitle`, you declare a `price` variable typed as `number` and an `inStock` variable typed as `boolean`, then log a single sentence that uses all three (something like `"The Midnight Library" costs $14.99 and is in stock: true`). Recompile with `tsc` and run the result with `node dist/index.js` to see it print.
