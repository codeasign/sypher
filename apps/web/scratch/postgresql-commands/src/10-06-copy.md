`COPY` is PostgreSQL's fast bulk loader and exporter. It moves whole tables, or the result of a query, to and from text files (usually CSV) far faster than a long list of `INSERT` statements.

## What you'll learn

- Exporting a table or a query with `COPY ... TO`
- Loading data with `COPY ... FROM`
- `COPY` (server side) versus `\copy` (your computer)
- CSV options: `HEADER`, `DELIMITER`, `NULL`

## Syntax

```sql show
COPY table_name (column1, column2) TO STDOUT WITH (FORMAT csv, HEADER);
COPY (SELECT ...) TO '/path/file.csv' WITH (FORMAT csv, HEADER);
COPY table_name FROM STDIN WITH (FORMAT csv, HEADER);
```

## Examples

### Export a query to the screen

`TO STDOUT` sends the result to the client. In `psql` that is your terminal:

```psql
COPY (SELECT category_id, name FROM category ORDER BY category_id LIMIT 4) TO STDOUT WITH (FORMAT csv, HEADER);
```

### Load rows from text

`FROM STDIN` reads the rows that follow, ending with a line containing `\.`:

```psql destructive
CREATE TABLE city_import (city text, population int);

COPY city_import FROM STDIN WITH (FORMAT csv, HEADER);
city,population
Lisbon,545000
Oslo,709000
Tokyo,
\.

SELECT * FROM city_import ORDER BY city;
```

The empty value for Tokyo became `NULL`, because in CSV format an unquoted empty field is `NULL`.

### Round trip through a file

`COPY` on the server reads and writes files on the **database server's** disk, and needs special rights. Here the server is the container, so this stays inside it:

```psql destructive
COPY (SELECT film_id, title FROM film ORDER BY film_id LIMIT 3) TO '/tmp/films.csv' WITH (FORMAT csv, HEADER);
CREATE TABLE film_import (film_id int, title text);
COPY film_import FROM '/tmp/films.csv' WITH (FORMAT csv, HEADER);
SELECT * FROM film_import ORDER BY film_id;
```

### Your own files: \copy

`\copy` is a `psql` command that does the same but reads and writes files on **your** computer, using your rights. This is what you use in practice (shown here, not run):

```sql show
\copy film (film_id, title) TO 'films.csv' WITH (FORMAT csv, HEADER)
\copy film_import FROM 'films.csv' WITH (FORMAT csv, HEADER)
```

## Try it yourself

Export the `customer` table's `first_name`, `last_name` and `email` to a CSV file with `\copy`, then load it into a new table with the same columns.

## Watch out

### COPY TO a file needs rights and lands on the server

Plain `COPY ... TO '/path'` writes on the database server, not on your laptop, and requires superuser or the `pg_write_server_files` role. Use `\copy` or `TO STDOUT` from a client.

### The column list must match the file

If the file has three columns and the table two (or in another order), the load fails or puts values in the wrong place. Name the columns explicitly in the `COPY`.

### One bad row fails the whole load

By default `COPY` is all-or-nothing: one malformed line aborts everything. PostgreSQL 17 added `ON_ERROR ignore` to skip bad rows, but it is safer to load into a staging table first and validate.

### COPY does not run rules like ON CONFLICT

`COPY` cannot skip duplicates. Load into a temporary staging table, then `INSERT ... SELECT ... ON CONFLICT DO NOTHING` into the real one.

## Interview corner

**"How do you load a large CSV file into PostgreSQL quickly?"**
`COPY table FROM 'file' WITH (FORMAT csv, HEADER)`, or `\copy` from `psql` for a file on your own machine. It is much faster than many `INSERT`s.

**"What is the difference between `COPY` and `\copy`?"**
`COPY` runs on the server and reads or writes files on the server's disk. `\copy` is a `psql` command that reads or writes files on the client and streams the data through the connection.

**"How do you export a query result to CSV?"**
`\copy (SELECT ...) TO 'out.csv' CSV HEADER`, or `COPY (SELECT ...) TO STDOUT WITH (FORMAT csv, HEADER)`.

## Practice

### Warm-up: a file round trip

Export the distinct film `rating`s to the server file `/tmp/ratings.csv` (CSV with a header), load that file into a new table `rating_import (rating text)`, and return how many rows it has as `ratings_loaded`.

```sql practice destructive
-- hint: `COPY (SELECT DISTINCT rating::text FROM film) TO '/tmp/ratings.csv' WITH (FORMAT csv, HEADER)`, then `COPY rating_import FROM ...`.
COPY (SELECT DISTINCT rating::text AS rating FROM film) TO '/tmp/ratings.csv' WITH (FORMAT csv, HEADER);
CREATE TABLE rating_import (rating text);
COPY rating_import FROM '/tmp/ratings.csv' WITH (FORMAT csv, HEADER);

SELECT COUNT(*) AS ratings_loaded FROM rating_import;
```

### Core: export a slice, load it back

Export the `first_name` and `last_name` of the customers of store 2 to `/tmp/store2.csv`, load them into a new table `store2_people (first_name text, last_name text)`, and return how many people were loaded (`people`).

```sql practice destructive
-- hint: `COPY (SELECT first_name, last_name FROM customer WHERE store_id = 2) TO ...`, then `COPY store2_people FROM ...`.
COPY (SELECT first_name, last_name FROM customer WHERE store_id = 2) TO '/tmp/store2.csv' WITH (FORMAT csv, HEADER);
CREATE TABLE store2_people (first_name text, last_name text);
COPY store2_people FROM '/tmp/store2.csv' WITH (FORMAT csv, HEADER);

SELECT COUNT(*) AS people FROM store2_people;
```

### Stretch: stage, then upsert

The table `stock_final (film_id int PRIMARY KEY, copies int)` holds film 1 with 5 copies and film 2 with 5. A file `/tmp/delta.csv` (written by your first statement from a query) holds `film_id,copies` rows for films 1 and 3, with 9 and 4 copies. Load it into a staging table, then move it into `stock_final` with `INSERT ... ON CONFLICT DO UPDATE` so film 1 becomes 9 and film 3 is added. Return the final table ordered by film.

```sql practice destructive
-- hint: `COPY (VALUES (1, 9), (3, 4)) TO '/tmp/delta.csv' ...`; stage it; `ON CONFLICT (film_id) DO UPDATE SET copies = EXCLUDED.copies`.
CREATE TABLE stock_final (film_id int PRIMARY KEY, copies int);
INSERT INTO stock_final VALUES (1, 5), (2, 5);
COPY (VALUES (1, 9), (3, 4)) TO '/tmp/delta.csv' WITH (FORMAT csv, HEADER);
CREATE TEMP TABLE stock_stage (film_id int, copies int);
COPY stock_stage FROM '/tmp/delta.csv' WITH (FORMAT csv, HEADER);

INSERT INTO stock_final SELECT * FROM stock_stage
ON CONFLICT (film_id) DO UPDATE SET copies = EXCLUDED.copies;

SELECT film_id, copies FROM stock_final ORDER BY film_id;
```
