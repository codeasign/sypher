`CASE` is SQL's if / else. It looks at a row and returns different values depending on which condition is true. Use it to label, group and re-shape data.

## What you'll learn

- The searched `CASE WHEN ... THEN ... ELSE ... END`
- The simple `CASE column WHEN value ...`
- Using `CASE` in `SELECT`, `ORDER BY` and `WHERE`
- Counting with `CASE`, and the shorter `FILTER`

## Syntax

```sql show
CASE
  WHEN condition1 THEN result1
  WHEN condition2 THEN result2
  ELSE other_result
END
```

`CASE` is an expression: it produces a value, so it can go anywhere a value can. Always finish it with `END`.

## Examples

### Labelling rows

Sort films into length bands:

```sql run
SELECT title, length,
       CASE
         WHEN length < 60 THEN 'Short'
         WHEN length < 120 THEN 'Medium'
         ELSE 'Long'
       END AS band
FROM film
ORDER BY film_id
LIMIT 5;
```

PostgreSQL tests the `WHEN` lines from top to bottom and stops at the first one that is true.

### The simple form

When you compare **one column** with several exact values, there is a shorter form:

```sql run
SELECT DISTINCT rating,
       CASE rating
         WHEN 'G' THEN 'Everyone'
         WHEN 'PG' THEN 'Parental guidance'
         WHEN 'PG-13' THEN 'Age 13+'
         ELSE 'Adults'
       END AS audience
FROM film
ORDER BY rating;
```

### CASE for money

Label each payment:

```sql run
SELECT payment_id, amount,
       CASE WHEN amount = 0 THEN 'Free' WHEN amount < 3 THEN 'Small' ELSE 'Large' END AS size
FROM payment
ORDER BY payment_id
LIMIT 5;
```

### CASE in ORDER BY

Put a custom order on the results. Here, PG-13 and R films come first and everything else follows:

```sql run
SELECT title, rating
FROM film
ORDER BY CASE WHEN rating IN ('PG-13', 'R') THEN 0 ELSE 1 END, title
LIMIT 5;
```

### Counting with CASE, and FILTER

Put a `CASE` inside `SUM` to count rows that meet a condition. This gives one row of results, with the numbers side by side (a *pivot*). PostgreSQL also has a shorter, clearer way: the `FILTER` clause.

```sql run
SELECT SUM(CASE WHEN length < 60 THEN 1 ELSE 0 END) AS short_with_case,
       COUNT(*) FILTER (WHERE length < 60) AS short_with_filter
FROM film;
```

## Watch out

### The first true condition wins

Order your `WHEN` lines carefully. Here the conditions overlap, so `Long` can never be reached (a 150 minute film already matches `length > 60`):

```sql run
SELECT title, length,
       CASE WHEN length > 60 THEN 'Medium' WHEN length > 120 THEN 'Long' ELSE 'Short' END AS band
FROM film
WHERE length = 150
ORDER BY film_id
LIMIT 2;
```

Put the strictest condition first.

### No ELSE means NULL

If no `WHEN` matches and there is no `ELSE`, the result is `NULL`, not an error. Add an `ELSE` unless you want the blank.

### All results must have one type

Mixing numbers and text in one `CASE` is an error in PostgreSQL (it will not guess). Keep every `THEN` the same type, or cast them.

## Interview corner

**"How do you write if / else logic in SQL?"**
With `CASE WHEN ... THEN ... ELSE ... END`. It is standard SQL and works in `SELECT`, `WHERE`, `ORDER BY` and inside aggregates.

**"How would you pivot rows into columns?"**
Put a `CASE` inside an aggregate: `SUM(CASE WHEN category = 'x' THEN 1 ELSE 0 END)`, or in PostgreSQL `COUNT(*) FILTER (WHERE category = 'x')`, for each column you want.

**"What does `COUNT(*) FILTER (WHERE ...)` do?"**
It counts only the rows that satisfy the condition. It is a PostgreSQL (and standard SQL) shorthand for `COUNT(CASE WHEN ... THEN 1 END)`.

## Practice

### Warm-up: active or not

Show each customer's `first_name`, `last_name` and a column `status` that says `Active` when `active = 1` and `Inactive` otherwise. Order by `customer_id`. Show the first rows.

```sql practice
-- hint: `CASE WHEN active = 1 THEN 'Active' ELSE 'Inactive' END`.
SELECT first_name, last_name, CASE WHEN active = 1 THEN 'Active' ELSE 'Inactive' END AS status
FROM customer
ORDER BY customer_id;
```

### Core: price bands

Show each film's `title`, `rental_rate` and a column `price_band`: `Budget` when the rate is below 1, `Regular` when below 3, and `Premium` otherwise. Order by `film_id`. Show the first rows.

```sql practice
-- hint: Test the smallest limit first.
SELECT title, rental_rate,
       CASE WHEN rental_rate < 1 THEN 'Budget' WHEN rental_rate < 3 THEN 'Regular' ELSE 'Premium' END AS price_band
FROM film
ORDER BY film_id;
```

### Stretch: a one-row summary

In a single row, count how many films are `Budget` (rate below 1), `Regular` (below 3) and `Premium` (3 or more), using `FILTER`. Return the columns `budget`, `regular` and `premium`.

```sql practice
-- hint: `COUNT(*) FILTER (WHERE rental_rate < 1)` and so on.
SELECT COUNT(*) FILTER (WHERE rental_rate < 1) AS budget,
       COUNT(*) FILTER (WHERE rental_rate >= 1 AND rental_rate < 3) AS regular,
       COUNT(*) FILTER (WHERE rental_rate >= 3) AS premium
FROM film;
```
