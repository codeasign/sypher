`IN` checks whether a value matches any value in a list. It is a shorter, cleaner way to write several `OR` conditions on the same column.

## What you'll learn

- Testing a value against a list
- `IN` as a shortcut for repeated `OR`
- `IN` with a list of numbers or text

## Syntax

```sql
SELECT column1
FROM table_name
WHERE column IN (value1, value2, value3);
```

## Examples

### A list of text values

Films rated G or PG:

```sql
SELECT title, rating
FROM film
WHERE rating IN ('G', 'PG')
ORDER BY title;
```

| title | rating |
|---|---|
| ACADEMY DINOSAUR | PG |
| ACE GOLDFINGER | G |
| AFFAIR PREJUDICE | G |
| AFRICAN EGG | G |
| AGENT TRUMAN | PG |
| … | … |

*Showing the first 5 of 372 rows.*

### A list of numbers

Customers in stores 1 and 2 with particular ids:

```sql
SELECT customer_id, first_name, last_name
FROM customer
WHERE customer_id IN (1, 10, 100, 500)
ORDER BY customer_id;
```

| customer_id | first_name | last_name |
|---:|---|---|
| 1 | MARY | SMITH |
| 10 | DOROTHY | TAYLOR |
| 100 | ROBIN | HAYES |
| 500 | REGINALD | KINDER |

*4 rows returned.*

### Same as a string of ORs

`IN` and repeated `OR` give the same rows. These two counts match:

```sql
SELECT COUNT(*) AS with_in FROM film WHERE rating IN ('G', 'PG', 'PG-13');
SELECT COUNT(*) AS with_or FROM film WHERE rating = 'G' OR rating = 'PG' OR rating = 'PG-13';
```

| with_in |
|---:|
| 595 |

*1 row returned.*

| with_or |
|---:|
| 595 |

*1 row returned.*

`IN` is easier to read, and easier to extend when you need one more value.

## Try it yourself

Find the films whose `rental_duration` is `3` or `7`, and the actors whose `first_name` is `'ED'`, `'JOE'` or `'BEN'`.

## Watch out

### A NULL in the list never matches

`NULL` is never equal to anything, even `NULL`, so `IN` cannot find a `NULL` value:

```sql
SELECT NULL IN (1, 2, NULL) AS result;
```

| result |
|---|
| NULL |

*1 row returned.*

The answer is empty (unknown), not true. Use `IS NULL` when you are looking for empty values.

### Strings must be quoted, numbers must not

`IN ('1', '2')` on a numeric column works (MySQL converts), but it hides bugs. Match the list's type to the column's type.

## Interview corner

**"What is the difference between `IN` and `OR`?"**
Nothing in the result: `col IN (a, b, c)` is a shorthand for `col = a OR col = b OR col = c`. `IN` reads better, and can also take a subquery instead of a fixed list.

**"Can `IN` contain a subquery?"**
Yes: `WHERE film_id IN (SELECT film_id FROM inventory)`. You will use this in Module 8.

### Stretch: two conditions, one list

Show `title`, `rating` and `length` of films rated `PG-13` or `R` that are shorter than 55 minutes. Shortest first, then title.

**Your result should look like this:**

| title | rating | length |
|---|---|---:|
| KWAI HOMEWARD | PG-13 | 46 |
| LABYRINTH LEAGUE | PG-13 | 46 |
| RIDGEMONT SUBMARINE | PG-13 | 46 |
| HALLOWEEN NUTS | PG-13 | 47 |
| HAWK CHILL | PG-13 | 47 |
| … | … | … |

*Showing the first 5 of 21 rows.*

<details>
<summary>Hint</summary>

Combine `IN` with `AND`. No brackets are needed since `IN` is a single condition.

</details>

<details>
<summary>Show solution</summary>

```sql
SELECT title, rating, length
FROM film
WHERE rating IN ('PG-13', 'R') AND length < 55
```
