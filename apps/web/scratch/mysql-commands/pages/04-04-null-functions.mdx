`NULL` spreads: any calculation that touches it becomes `NULL`. A few small functions let you replace, create or test for `NULL` so your reports show something sensible.

## What you'll learn

- `IFNULL` and `COALESCE`: replace `NULL` with a default
- `NULLIF`: turn a value into `NULL`
- `ISNULL` and `IF`

## Syntax

```sql
IFNULL(value, replacement)
COALESCE(value1, value2, value3, ...)
NULLIF(value1, value2)
```

## Examples

### IFNULL

`IFNULL(a, b)` returns `a`, or `b` if `a` is `NULL`. Unreturned rentals have no `return_date`:

```sql
SELECT rental_id, IFNULL(return_date, 'not returned yet') AS return_status
FROM rental
WHERE rental_id IN (1, 11496, 11541)
ORDER BY rental_id;
```

| rental_id | return_status |
|---:|---|
| 1 | 2005-05-26 22:04:30 |
| 11496 | not returned yet |
| 11541 | not returned yet |

*3 rows returned.*

### COALESCE

`COALESCE` returns the first value in its list that is not `NULL`. It can take any number of arguments:

```sql
SELECT COALESCE(NULL, NULL, 'third choice', 'fourth choice') AS first_non_null;
```

| first_non_null |
|---|
| third choice |

*1 row returned.*

### NULLIF

`NULLIF(a, b)` returns `NULL` if `a` equals `b`, and `a` otherwise. It is handy for turning "empty" markers into a true `NULL`. In this database most `address2` values are `''`, not `NULL`, so combine the two functions:

```sql
SELECT address_id,
       address2,
       COALESCE(NULLIF(address2, ''), 'no second line') AS second_line
FROM address
ORDER BY address_id;
```

| address_id | address2 | second_line |
|---:|---|---|
| 1 | NULL | no second line |
| 2 | NULL | no second line |
| 3 | NULL | no second line |
| 4 | NULL | no second line |
| 5 |  | no second line |
| … | … | … |

*Showing the first 5 of 603 rows.*

### Avoiding division by zero

Dividing by `NULL` gives `NULL`, so `NULLIF(x, 0)` turns a zero divisor into a harmless `NULL`:

```sql
SELECT 10 / NULLIF(0, 0) AS safe_division;
```

| safe_division |
|---|
| NULL |

*1 row returned.*

### IF and ISNULL

`IF(condition, if_true, if_false)` picks one of two values. `ISNULL(x)` gives `1` if `x` is `NULL`, else `0`:

```sql
SELECT rental_id,
       IF(return_date IS NULL, 'out', 'back') AS status,
       ISNULL(return_date) AS is_out
FROM rental
WHERE rental_id IN (1, 11496)
ORDER BY rental_id;
```

| rental_id | status | is_out |
|---:|---|---:|
| 1 | back | 0 |
| 11496 | out | 1 |

*2 rows returned.*

## Watch out

### IFNULL does not handle empty strings

`IFNULL(address2, 'n/a')` leaves `''` as `''`, because an empty string is not `NULL`. Use `NULLIF` first, as above.

### Both branches should have the same type

`IFNULL(return_date, 'not returned yet')` mixes a date with text, so MySQL turns the whole column into text. That is fine for display, but do not sort or calculate on it afterwards.

## Interview corner

**"What is the difference between `IFNULL` and `COALESCE`?"**
`IFNULL` takes exactly two arguments and is MySQL-specific. `COALESCE` takes any number, returns the first non-`NULL`, and is part of standard SQL, so it works in other databases.

**"How do you avoid a division by zero?"**
Divide by `NULLIF(divisor, 0)`, so a zero divisor makes the result `NULL` instead of an error or a wrong number.
