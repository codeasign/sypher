A comment is text that MySQL ignores. You use comments to explain a query to the next person who reads it, or to switch part of a query off while you experiment.

## What you'll learn

- The three comment styles: `-- `, `#` and `/* */`
- When to comment out part of a query
- The classic `--` gotcha

## Syntax

```sql
-- a single-line comment (note the space after the two dashes)
# another single-line comment, MySQL only
/* a comment that can
   span several lines */
```

## Examples

### Single-line comments

Everything after `-- ` (two dashes and a space) to the end of the line is ignored:

```sql
SELECT title, rating -- these are the columns we want
FROM film
WHERE film_id = 1;
```

| title | rating |
|---|---|
| ACADEMY DINOSAUR | PG |

*1 row returned.*

`#` works the same way but is MySQL only. Prefer `-- ` because it works in every database.

### Multi-line comments

Anything between `/*` and `*/` is ignored, across as many lines as you like:

```sql
/*
  Purpose: show one film.
  Author: you
*/
SELECT title, length
FROM film
WHERE film_id = 1;
```

| title | length |
|---|---:|
| ACADEMY DINOSAUR | 86 |

*1 row returned.*

### Switching part of a query off

Comments are handy for testing. Here the `AND` condition is commented out, so it has no effect:

```sql
SELECT title, rating, length
FROM film
WHERE rating = 'G'
  /* AND length > 100 */
  AND film_id <= 5
ORDER BY film_id;
```

| title | rating | length |
|---|---|---:|
| ACE GOLDFINGER | G | 48 |
| AFFAIR PREJUDICE | G | 117 |
| AFRICAN EGG | G | 130 |

*3 rows returned.*

Take the comment marks away, and the extra condition applies.

## Try it yourself

Paste any query above into your lab and add a comment of your own to it.

## Watch out

### `--` needs a space after it

MySQL only treats `--` as a comment when a space (or a line break) follows. Without the space, it is two minus signs:

```sql
SELECT 10--5 AS without_space;
```

| without_space |
|---:|
| 15 |

*1 row returned.*

The result is `15`, not `10`: MySQL read `10 - (-5)`. Write `-- ` with the space, every time.

### Don't leave secrets in comments

Comments are part of your saved code. Do not put passwords or private notes in them.

## Interview corner

**"How do you write comments in MySQL?"**
Three ways: `-- ` (with a space), `#`, and `/* ... */` for blocks.

**"Why does `SELECT 10--5` not behave like a comment?"**
`--` is only a comment marker when followed by whitespace, so without the space it is parsed as `10 - (-5)`.
