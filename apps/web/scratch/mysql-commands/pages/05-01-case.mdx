`CASE` is SQL's if / else. It looks at a row and returns different values depending on which condition is true. Use it to label, group and re-shape data.

## What you'll learn

- The searched `CASE WHEN ... THEN ... ELSE ... END`
- The simple `CASE column WHEN value ...`
- Using `CASE` in `SELECT`, `ORDER BY` and `WHERE`

## Syntax

```sql
CASE
  WHEN condition1 THEN result1
  WHEN condition2 THEN result2
  ELSE default_result
END
```

`CASE` is an expression: it produces a value, so it can go anywhere a value can. Always finish it with `END`.

## Examples

### Labelling rows

Sort films into length bands:

```sql
SELECT title, length,
       CASE
         WHEN length < 60 THEN 'Short'
         WHEN length <= 120 THEN 'Medium'
         ELSE 'Long'
       END AS length_band
FROM film
ORDER BY film_id;
```

| title | length | length_band |
|---|---:|---|
| ACADEMY DINOSAUR | 86 | Medium |
| ACE GOLDFINGER | 48 | Short |
| ADAPTATION HOLES | 50 | Short |
| AFFAIR PREJUDICE | 117 | Medium |
| AFRICAN EGG | 130 | Long |
| … | … | … |

*Showing the first 5 of 1000 rows.*

MySQL tests the `WHEN` lines from top to bottom and stops at the first one that is true.

### The simple form

When you compare **one column** with several exact values, there is a shorter form:

```sql
SELECT title, rating,
       CASE rating
         WHEN 'G' THEN 'Everyone'
         WHEN 'PG' THEN 'Parental guidance'
         WHEN 'PG-13' THEN 'Age 13+'
         WHEN 'R' THEN 'Age 17+'
         ELSE 'Adults only'
       END AS audience
FROM film
ORDER BY film_id;
```

| title | rating | audience |
|---|---|---|
| ACADEMY DINOSAUR | PG | Parental guidance |
| ACE GOLDFINGER | G | Everyone |
| ADAPTATION HOLES | NC-17 | Adults only |
| AFFAIR PREJUDICE | G | Everyone |
| AFRICAN EGG | G | Everyone |
| … | … | … |

*Showing the first 5 of 1000 rows.*

### CASE for money

Label each payment:

```sql
SELECT payment_id, amount,
       CASE
         WHEN amount = 0 THEN 'Free'
         WHEN amount < 3 THEN 'Low'
         WHEN amount < 7 THEN 'Standard'
         ELSE 'High'
       END AS payment_tier
FROM payment
ORDER BY payment_id;
```

| payment_id | amount | payment_tier |
|---:|---:|---|
| 1 | 2.99 | Low |
| 2 | 0.99 | Low |
| 3 | 5.99 | Standard |
| 4 | 0.99 | Low |
| 5 | 9.99 | High |
| … | … | … |

*Showing the first 5 of 16044 rows.*

### CASE in ORDER BY

Put a custom order on the results. Here, PG-13 and R films come first and everything else follows:

```sql
SELECT title, rating
FROM film
ORDER BY CASE WHEN rating IN ('PG-13', 'R') THEN 0 ELSE 1 END, title;
```

| title | rating |
|---|---|
| AIRPLANE SIERRA | PG-13 |
| AIRPORT POLLOCK | R |
| ALABAMA DEVIL | PG-13 |
| ALONE TRIP | R |
| ALTER VICTORY | PG-13 |
| … | … |

*Showing the first 5 of 1000 rows.*

### Counting with CASE

Put a `CASE` inside `SUM` to count rows that meet a condition. This gives one row of results, with the numbers side by side (a *pivot*):

```sql
SELECT SUM(CASE WHEN length < 60 THEN 1 ELSE 0 END) AS short_films,
       SUM(CASE WHEN length BETWEEN 60 AND 120 THEN 1 ELSE 0 END) AS medium_films,
       SUM(CASE WHEN length > 120 THEN 1 ELSE 0 END) AS long_films
FROM film;
```

| short_films | medium_films | long_films |
|---:|---:|---:|
| 96 | 447 | 457 |

*1 row returned.*

## Watch out

### The first true condition wins

Order your `WHEN` lines carefully. Here the conditions overlap, so `Long` can never be reached (a 150 minute film already matches `length > 60`):

```sql
SELECT SUM(CASE WHEN length > 60 THEN 1 ELSE 0 END) AS matched_medium,
       SUM(CASE WHEN length > 60 THEN 0 WHEN length > 120 THEN 1 ELSE 0 END) AS ever_reaches_long
FROM film;
```

| matched_medium | ever_reaches_long |
|---:|---:|
| 896 | 0 |

*1 row returned.*

Put the strictest condition first.

### No ELSE means NULL

If no `WHEN` matches and there is no `ELSE`, the result is `NULL`, not an error. Add an `ELSE` unless you want the blank.

### All results should be the same type

Mixing numbers and text in one `CASE` forces MySQL to convert one of them, which can give odd results. Keep every `THEN` the same type.

## Interview corner

**"How do you write if / else logic in SQL?"**
With `CASE WHEN ... THEN ... ELSE ... END` (standard SQL), or `IF(condition, a, b)` in MySQL for a simple two-way choice.

**"How would you pivot rows into columns?"**
Put a `CASE` inside an aggregate: `SUM(CASE WHEN category = 'x' THEN 1 ELSE 0 END)` for each column you want, without a `GROUP BY` (one row) or with one (a row per group).

### Stretch: a one-row summary

In a single row, count how many films are `Budget` (rate below 1), `Regular` (below 3) and `Premium` (3 or more). Return the columns `budget`, `regular` and `premium`.

**Your result should look like this:**

| budget | regular | premium |
|---:|---:|---:|
| 341 | 323 | 336 |

*1 row returned.*

<details>
<summary>Hint</summary>

Three `SUM(CASE WHEN ... THEN 1 ELSE 0 END)` columns.

</details>

<details>
<summary>Show solution</summary>

```sql
SELECT SUM(CASE WHEN rental_rate < 1 THEN 1 ELSE 0 END) AS budget,
       SUM(CASE WHEN rental_rate >= 1 AND rental_rate < 3 THEN 1 ELSE 0 END) AS regular,
       SUM(CASE WHEN rental_rate >= 3 THEN 1 ELSE 0 END) AS premium
FROM film;
```
