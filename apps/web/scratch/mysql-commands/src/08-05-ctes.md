A **CTE** (common table expression) is a named, temporary result you define at the top of a query with `WITH`, then use like a table. It turns a tangle of nested subqueries into steps you can read from top to bottom.

## What you'll learn

- Writing a query with `WITH`
- Chaining several CTEs
- Recursive CTEs for series and sequences

## Syntax

```sql show
WITH cte_name AS (
  SELECT ...
)
SELECT ...
FROM cte_name;
```

## Examples

### Step one, then step two

Total spending per customer first, then compare with the average. Each step has a name:

```sql run
WITH per_customer AS (
  SELECT customer_id, SUM(amount) AS total_spent
  FROM payment
  GROUP BY customer_id
)
SELECT customer_id, total_spent
FROM per_customer
WHERE total_spent > (SELECT AVG(total_spent) FROM per_customer)
ORDER BY total_spent DESC, customer_id;
```

This is the question from the subquery page, and you can now read it in order. A CTE can also be used more than once in the same query.

### Several CTEs

Separate them with commas. Each can use the ones before it:

```sql run
WITH per_customer AS (
  SELECT customer_id, SUM(amount) AS total_spent
  FROM payment
  GROUP BY customer_id
),
bands AS (
  SELECT customer_id,
         total_spent,
         CASE WHEN total_spent >= 150 THEN 'High' WHEN total_spent >= 100 THEN 'Medium' ELSE 'Low' END AS band
  FROM per_customer
)
SELECT band, COUNT(*) AS customers
FROM bands
GROUP BY band
ORDER BY customers DESC;
```

### A recursive CTE: counting

A recursive CTE refers to itself. It starts with an *anchor* row and keeps adding rows until a stopping condition. Numbers 1 to 10:

```sql run
WITH RECURSIVE numbers AS (
  SELECT 1 AS n
  UNION ALL
  SELECT n + 1 FROM numbers WHERE n < 10
)
SELECT n FROM numbers;
```

### A recursive CTE: filling in the gaps

Generate every day in a range and left-join the data, so days with **no** payments still appear (with 0). This data has a gap: nothing was paid for in early June, and a plain `GROUP BY` on the payments would simply skip those days:

```sql run
WITH RECURSIVE days AS (
  SELECT DATE '2005-05-29' AS day
  UNION ALL
  SELECT day + INTERVAL 1 DAY FROM days WHERE day < '2005-06-03'
)
SELECT d.day, COUNT(p.payment_id) AS payments
FROM days AS d
LEFT JOIN payment AS p ON DATE(p.payment_date) = d.day
GROUP BY d.day
ORDER BY d.day;
```

## Watch out

### A CTE lasts for one query

It is not stored. Once the statement ends, the name is gone (a *view*, Module 15, is the permanent version).

### Recursive CTEs need a way to stop

Every pass must eventually stop adding rows. MySQL also protects you with a recursion limit (1000 by default):

```sql run error
WITH RECURSIVE numbers AS (
  SELECT 1 AS n
  UNION ALL
  SELECT n + 1 FROM numbers
)
SELECT COUNT(*) FROM numbers;
```

Always include a `WHERE` that ends the recursion.

### The anchor and recursive parts must have the same columns

Both parts of the `UNION ALL` must return the same number of columns, of compatible types.

## Interview corner

**"What is a CTE, and how is it different from a subquery?"**
A CTE is a named subquery defined first with `WITH`. It reads better, can be reused within the statement, and allows recursion. A plain subquery is written inline and has no name to reuse.

**"What is a recursive CTE used for?"**
Sequences (numbers, dates) and hierarchies such as an employee-manager chain or a category tree.

**"Is a CTE faster than a subquery?"**
Not by itself. It is mainly a readability tool; MySQL may treat it like a derived table or a view.

## Practice

### Warm-up: rewrite with WITH

Using a CTE called `film_stats`, compute per `rating` the number of films and the average length, then show the ratings whose average length is above 115. Return `rating`, `films` and `avg_length` (rounded to 1 decimal), ordered by rating.

```sql practice
-- hint: Put `GROUP BY rating` with `COUNT(*)` and `AVG(length)` in the CTE; filter outside it.
WITH film_stats AS (
  SELECT rating, COUNT(*) AS films, ROUND(AVG(length), 1) AS avg_length
  FROM film
  GROUP BY rating
)
SELECT rating, films, avg_length
FROM film_stats
WHERE avg_length > 115
ORDER BY rating;
```

### Core: count to 12

Use a recursive CTE to return the numbers 1 to 12, in a single column called `month_number`.

```sql practice rows=6
-- hint: Anchor at 1, add one each pass, stop when the number reaches 12.
WITH RECURSIVE months AS (
  SELECT 1 AS month_number
  UNION ALL
  SELECT month_number + 1 FROM months WHERE month_number < 12
)
SELECT month_number
FROM months;
```

### Stretch: quiet days

Using a recursive CTE for the days from `2005-05-30` to `2005-06-03`, show each day with the number of **rentals** made that day (`rentals`), including days with none. Order by day.

```sql practice
-- hint: Same pattern as the payments example, but with `rental_date` on the `rental` table.
WITH RECURSIVE days AS (
  SELECT DATE '2005-05-30' AS day
  UNION ALL
  SELECT day + INTERVAL 1 DAY FROM days WHERE day < '2005-06-03'
)
SELECT d.day, COUNT(r.rental_id) AS rentals
FROM days AS d
LEFT JOIN rental AS r ON DATE(r.rental_date) = d.day
GROUP BY d.day
ORDER BY d.day;
```
