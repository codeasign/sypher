The same defects, tagged by which technique caught them: 38 from scripted test cases, 27 from unscripted exploratory sessions, 24 from the automated suite.

| Technique | Defects found | Share |
| --- | --- | --- |
| Scripted | 38 | 42.7% |
| Exploratory | 27 | 30.3% |
| Automated | 24 | 27% |

![Donut chart of Harbor QA defects found split across scripted, exploratory, and automated testing techniques](https://syhpher-next-datastore-gvaf.b-cdn.net/svgs/measuring-test-effectiveness/defects-by-technique.svg)

*Shown as a donut chart because this is composition, how the whole set of found defects splits by which technique caught them.*

Scripted testing found the most at 42.7%, but exploratory testing, unplanned, tester-driven sessions with no fixed script, found 30.3%, a substantial share for something that costs no authoring time and adapts instantly to whatever changed that release.

This chart is the strongest argument Harbor QA had for protecting exploratory testing time when release schedules got tight. It is often the first thing cut under deadline pressure, and this breakdown shows that cutting it would have meant missing over a quarter of the defects testing actually caught.
