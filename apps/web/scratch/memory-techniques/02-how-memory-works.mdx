Think of the last time you walked into a room and forgot why. You were not broken. Something ordinary happened: the thought you had a second ago never got stored.

Understanding the basic steps helps you see where things go missing.

## Three steps

Encoding is taking in information. Storing is keeping it. Retrieval is getting it back out. A memory can fail at any step, but most everyday forgetting happens at the first one. If you never really took it in, there is nothing to find later.

## Short-term and long-term

Short-term memory holds a small amount for a few seconds, such as a phone number you are about to dial. It can only hold a handful of items at once, often about four to seven. Long-term memory stores information for days or years, and it seems to have no practical limit.

To move something from short-term to long-term, you need to give it meaning, connect it to something you already know, or revisit it.

## We forget fast, then slowly

Studies going back to the 1880s show that forgetting is steep at first. Much of what you learn is gone within a day if you do nothing with it. The drop then slows. Reviewing at the right times flattens this curve, and lesson 8 shows how.

## Memory is rebuilt, not replayed

Each time you recall something, you reconstruct it. That is why two people remember the same event differently, and why writing things down matters. Your recall is usually reasonable, but not exact.

Bad version: "I have a terrible memory, so there is no point trying."

Better version: "My memory works best with pictures and repetition. I will use those for the things I need."

The better version works because it points to what you can change, which is how you take information in.

## Why the techniques work

Every technique in this course makes information more vivid, more connected, or more often revisited. Those are the three things the brain rewards.

## TRY IT

Exercise 1. You forget where you left your keys most mornings. At which step did the memory probably fail?

**Suggested answer:** Encoding. You put them down without paying attention. Saying "keys on the hook" out loud as you place them helps.

Exercise 2. Why does cramming for one night often fail?

**Suggested answer:** Most of the information stays in short-term memory and fades quickly. Spreading the review over days keeps more of it.

Exercise 3. Write one sentence using "my memory works best when...".

**Suggested answer:** For example: "My memory works best when I see it, draw it, or explain it to someone."
