You meet someone at a party. They tell you their name. Ten seconds later, you cannot remember it, and you were listening.

That is the most common memory complaint in the world, and it is not a sign that your memory is weak. Your memory is doing exactly what it was built to do: keep what seems important and let the rest fade. The name never got marked as important, so it faded.

Memory techniques are ways of marking things as important on purpose. They use how the brain already works, with pictures, stories, places, and repetition, so remembering takes less effort and lasts longer.

This course covers practical techniques you can use for names, lists, numbers, study material, and everyday tasks:

* How memory works, so the techniques make sense
* Why attention comes first
* How chunking makes long things short
* How to link facts using pictures and stories
* How to build a memory palace
* How to remember names and faces
* How to review at the right moments so facts stay for good
* How to remember numbers and long lists
* Daily habits that support your memory

Each lesson is short and ends with a TRY IT of two or three exercises. These techniques feel odd for the first few tries, like learning to type. Give each one a real attempt before deciding whether it suits you. Different people prefer different methods, and you only need the two or three that fit your life.

No special talent or training is needed. You only need to be willing to make silly pictures in your head, which is the part that actually works.
