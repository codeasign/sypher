`$lookup` is MongoDB's join. It looks up matching documents in another collection of the same database and adds them to each input document as an array. In this database, rentals point at films through `filmId`, and store inventory points at films too, so `$lookup` is how you connect them.

## What you'll learn

- The basic `$lookup` with `localField` and `foreignField`
- Turning the result array into a single value with `$unwind` or `$arrayElemAt`
- A pipeline `$lookup` with `let` for complex conditions
- Performance: indexes and when not to join

## Syntax

```js
{ $lookup: { from: "films", localField: "filmId", foreignField: "_id", as: "film" } }

{ $lookup: {
    from: "films",
    let: { id: "$filmId" },
    pipeline: [ { $match: { $expr: { $eq: ["$_id", "$$id"] } } }, { $project: { title: 1 } } ],
    as: "film"
} }
```

## Examples

### A basic join: rental to film

Take three rentals of customer 1 and attach the film document to each:

```js
db.customers.aggregate([
  { $match: { _id: 1 } },
  { $unwind: "$rentals" },
  { $limit: 3 },
  { $lookup: { from: "films", localField: "rentals.filmId", foreignField: "_id", as: "film" } },
  { $project: { _id: 0, rentalId: "$rentals.rentalId", film: { $arrayElemAt: ["$film.title", 0] }, matches: { $size: "$film" } } }
])
```

```text
[
  { rentalId: 76, film: 'PATIENT SISTER', matches: 1 },
  { rentalId: 573, film: 'TALENTED HOMICIDE', matches: 1 },
  { rentalId: 1185, film: 'MUSKETEERS WAIT', matches: 1 }
]
```

`as` is always an **array**, even when only one document matches. Use `$arrayElemAt` or `$unwind` to get a single value.

### $unwind after $lookup

```js
db.customers.aggregate([
  { $match: { _id: 1 } },
  { $unwind: "$rentals" },
  { $limit: 2 },
  { $lookup: { from: "films", localField: "rentals.filmId", foreignField: "_id", as: "film" } },
  { $unwind: "$film" },
  { $project: { _id: 0, rentalId: "$rentals.rentalId", title: "$film.title", rating: "$film.rating", rate: "$film.rentalRate" } }
])
```

```text
[
  {
    rentalId: 76,
    title: 'PATIENT SISTER',
    rating: 'NC-17',
    rate: 0.99
  },
  {
    rentalId: 573,
    title: 'TALENTED HOMICIDE',
    rating: 'PG',
    rate: 0.99
  }
]
```

### A useful report: revenue per category

Join every payment to its film's category and add it up:

```js
db.customers.aggregate([
  { $unwind: "$rentals" },
  { $lookup: { from: "films", localField: "rentals.filmId", foreignField: "_id", as: "film" } },
  { $unwind: "$film" },
  { $unwind: "$rentals.payments" },
  { $group: { _id: "$film.category.name", revenue: { $sum: "$rentals.payments.amount" } } },
  { $project: { revenue: { $round: ["$revenue", 2] } } },
  { $sort: { revenue: -1, _id: 1 } },
  { $limit: 3 }
])
```

```text
[
  { _id: 'Sports', revenue: 5314.21 },
  { _id: 'Sci-Fi', revenue: 4756.98 },
  { _id: 'Animation', revenue: 4656.3 }
]
```

### Left outer join behaviour

If nothing matches, the array is empty and the document is kept. Show films that no rental refers to:

```js
db.films.aggregate([
  { $lookup: { from: "customers", localField: "_id", foreignField: "rentals.filmId", as: "renters" } },
  { $match: { renters: { $size: 0 } } },
  { $project: { title: 1 } },
  { $sort: { _id: 1 } },
  { $limit: 3 }
])
```

```text
[
  { _id: 14, title: 'ALICE FANTASIA' },
  { _id: 33, title: 'APOLLO TEEN' },
  { _id: 36, title: 'ARGONAUTS TOWN' }
]
```

The join field can be inside an array (`rentals.filmId`): MongoDB matches any element.

### Pipeline lookup with let

When the join needs more than equality, use a sub-pipeline. `let` passes values of the outer document in as `$$variables`. Here: for a film, find the store inventory copies:

```js
db.films.aggregate([
  { $match: { _id: 1 } },
  { $lookup: {
      from: "stores",
      let: { fid: "$_id" },
      pipeline: [
        { $project: { _id: 1, copies: { $size: { $filter: { input: "$inventory", as: "i", cond: { $eq: ["$$i.filmId", "$$fid"] } } } } } },
        { $sort: { _id: 1 } }
      ],
      as: "stock"
  } },
  { $project: { _id: 0, title: 1, stock: 1 } }
])
```

```text
[
  {
    title: 'ACADEMY DINOSAUR',
    stock: [ { _id: 1, copies: 4 }, { _id: 2, copies: 4 } ]
  }
]
```

### Sub-pipeline limiting the joined data

Join only the fields you need, to keep documents small:

```js
db.films.aggregate([
  { $match: { _id: 1 } },
  { $lookup: {
      from: "customers",
      let: { fid: "$_id" },
      pipeline: [
        { $match: { "rentals.filmId": 1 } },
        { $project: { _id: 1, "name.last": 1 } },
        { $sort: { _id: 1 } },
        { $limit: 3 }
      ],
      as: "firstRenters"
  } },
  { $project: { _id: 0, title: 1, firstRenters: 1 } }
])
```

```text
[
  {
    title: 'ACADEMY DINOSAUR',
    firstRenters: [
      { _id: 8, name: { last: 'WILSON' } },
      { _id: 34, name: { last: 'SCOTT' } },
      { _id: 39, name: { last: 'NELSON' } }
    ]
  }
]
```

### Is the join field indexed?

The lookup runs once per input document, so the foreign field needs an index. This database indexes `rentals.filmId` on `customers` (`idx_customer_rental_film`):

```js
db.customers.getIndexes().map((i) => i.name).sort()
```

```text
[ '_id_', 'idx_customer_rental_film', 'uq_customer_email' ]
```

## Watch out

### `$lookup` output is an array

Even a one-to-one join gives an array of one. Use `$unwind` (or `$arrayElemAt`) before you access fields.

### Index the foreign field

Without an index on `foreignField`, each input document scans the entire other collection. On large data that is a disaster.

### A `$lookup` can produce huge documents

If thousands match, the `as` array can exceed 16 MB. Filter and project inside a sub-pipeline, or reverse the direction.

### `from` must be in the same database, and unsharded

In a sharded cluster the `from` collection cannot be sharded (before MongoDB 5.1). Check limits for your version.

### If you join in every query, reconsider the model

Frequent `$lookup`s often mean related data should be embedded (module 13).

## Interview corner

**"How do you join collections in MongoDB?"**
With the `$lookup` aggregation stage, which performs a left outer join and returns the matches as an array field.

**"What is the difference between the simple and pipeline forms of `$lookup`?"**
The simple form matches one local field to one foreign field. The pipeline form takes `let` variables and a sub-pipeline for complex conditions and shaping.

**"How do you make `$lookup` fast?"**
Index the foreign field, match early, limit fields with `$project`, and keep the input small.
