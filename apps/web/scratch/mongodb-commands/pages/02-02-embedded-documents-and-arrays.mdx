The power of a document is that it can hold other documents and lists. A film carries its category as a small document and its cast as an array of documents. You reach inside them with **dot notation**.

## What you'll learn

- Reading nested fields with dot notation
- Querying inside embedded documents
- Querying arrays of values and arrays of documents
- Array positions with `.0` and `$size`

## Syntax

```js
{ "category.name": "Horror" }           // field inside an embedded document
{ "actors.lastName": "GUINESS" }        // field inside array elements
{ "specialFeatures.0": "Trailers" }     // first element of an array
{ specialFeatures: { $size: 2 } }       // array length
```

## Examples

### Dot notation into a subdocument

A film's `category` is an embedded document `{ categoryId, name }`. To query its `name`, put the path in quotes:

```js
db.films.find({ "category.name": "Horror" }, { title: 1, "category.name": 1 }).sort({ _id: 1 }).limit(3)
```

```text
[
  { _id: 2, category: { name: 'Horror' }, title: 'ACE GOLDFINGER' },
  { _id: 4, category: { name: 'Horror' }, title: 'AFFAIR PREJUDICE' },
  { _id: 8, category: { name: 'Horror' }, title: 'AIRPORT POLLOCK' }
]
```

### Arrays of simple values

`specialFeatures` is a list of strings. A plain equality matches films whose list **contains** the value:

```js
db.films.countDocuments({ specialFeatures: "Trailers" })
```

```text
535
```

An exact array match needs the whole list, in order:

```js
db.films.countDocuments({ specialFeatures: ["Trailers", "Deleted Scenes"] })
```

```text
66
```

### Arrays of documents

`actors` is a list of small documents. A dotted path looks inside every element:

```js
db.films.find({ "actors.lastName": "GUINESS" }, { title: 1 }).sort({ _id: 1 }).limit(3)
```

```text
[
  { _id: 1, title: 'ACADEMY DINOSAUR' },
  { _id: 2, title: 'ACE GOLDFINGER' },
  { _id: 11, title: 'ALAMO VIDEOTAPE' }
]
```

### Positions and length

`.0` is the first element, and `$size` tests the length:

```js
db.films.countDocuments({ "specialFeatures.0": "Trailers" })
```

```text
535
```

```js
db.films.countDocuments({ specialFeatures: { $size: 4 } })
```

```text
61
```

### Nested arrays: rentals and payments

A customer has `rentals[]`, and each rental has `payments[]`. Dots go as deep as you need:

```js
db.customers.countDocuments({ "rentals.payments.amount": { $gt: 10 } })
```

```text
107
```

### Reading nested values in code

In the shell a document is a JavaScript object, so ordinary property access works:

```js
const c = db.customers.findOne({ _id: 1 });
[c.name.first + " " + c.name.last, c.address.country, c.rentals.length, c.rentals[0].payments[0].amount]
```

```text
[ 'MARY SMITH', 'Japan', 32, 2.99 ]
```

## Watch out

### Quotes around dotted paths

`{ category.name: "Horror" }` is a syntax error. Write `{ "category.name": "Horror" }`.

### Matching an embedded document exactly needs all fields, in order

`{ category: { name: "Horror" } }` does **not** match, because the stored subdocument also has `categoryId`. Use the dotted path instead.

### Array conditions can match different elements

`{ "actors.firstName": "ED", "actors.lastName": "CHASE" }` matches a film that has **some** actor named ED and **some** actor named CHASE, not necessarily the same person. Use `$elemMatch` (module 6) to require one element to satisfy both.

### Deeply nested arrays get heavy

A customer document contains every rental and payment. That is convenient to read and expensive to grow. Module 13 discusses when to stop embedding.

## Interview corner

**"How do you query a field inside an embedded document?"**
With dot notation in quotes: `{ "address.country": "Japan" }`.

**"How does a query on an array field work?"**
A condition on an array field matches if **any element** satisfies it (`{ tags: "a" }`). An exact array value must equal the whole array.

**"What is the difference between `{ a: { b: 1 } }` and `{ "a.b": 1 }`?"**
The first matches a subdocument exactly equal to `{ b: 1 }`. The second matches any document whose `a.b` is `1`, whatever else `a` holds.
