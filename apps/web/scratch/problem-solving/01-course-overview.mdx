The office printer jams every Monday. Someone opens the tray, pulls out the crumpled page, and restarts it. By Wednesday it works. By the next Monday it jams again, and someone else does the same thing.

Nobody in that office is bad at their job. They are all solving the problem in front of them, which is "the printer is stuck." Nobody is solving the problem behind it, which is "why does it jam every Monday?" (It turns out the paper gets damp over the weekend because the cupboard is next to a window.)

Problem solving is a way of working that gets you from the first kind of fix to the second. It is not a talent. It is a short list of habits, and you can practice them on small problems until they feel natural on big ones.

This course covers those habits one at a time:

* How to describe a problem so it can actually be solved
* How to break a large problem into pieces you can handle
* How to find the cause instead of patching the symptom
* How to come up with options before you judge them
* How to test a solution cheaply before you commit
* What to do when you are completely stuck
* How to solve problems with other people without a fight
* How to learn from what happened, so the same problem does not return

Each lesson is short and ends with a TRY IT of two or three exercises. Write your own answer first, then read the suggested one. If yours is different but reasonable, that is fine. The exercise is there to make you think, not to find one correct line.

You can use this course for work problems, home problems, or study problems. The examples mix all three on purpose, because the habits are the same everywhere.
