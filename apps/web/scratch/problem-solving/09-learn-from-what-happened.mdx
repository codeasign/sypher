title: "Learn from what happened"
order: 9
---

Fixing a problem and moving on feels like finishing. It is really the halfway point. The other half is understanding what the problem taught you, so it does not come back in a different form.

Teams that skip this step tend to solve the same problem every few months and call it bad luck.

## A short review

After a problem is solved, spend ten minutes on four questions:

* What happened?
* What did we do that helped?
* What did we miss, or what slowed us down?
* What will we change so it is less likely, or less painful, next time?

Do this in writing. A note in a shared document is enough.

## Keep the tone kind

The point is to improve the process, not to find someone to blame. If a person made a mistake, ask what made the mistake easy. Missing checklists, unclear handovers, and rushed schedules are more common causes than carelessness.

Bad version: "The problem happened because the new hire did not check the settings."

Better version: "The settings were not checked. The setup guide does not mention them. We will add a checklist."

The better version works because it produces something you can use. Blame produces a quiet team.

## Turn lessons into small changes

A lesson that is not attached to an action is just a story. Choose one small change, name the owner, and put it on the calendar. Small and done beats big and forgotten.

## Look for patterns

Once a quarter, read your past notes. You may see that three different problems all began with unclear requests. That pattern is more valuable than any single fix.

## Celebrate the fix honestly

If something worked, say so. It builds the habit of solving problems together and reminds people that the effort had an effect.

## TRY IT

Exercise 1. A meeting was double booked and a client waited twenty minutes. Write one process change.

**Suggested answer:** "Everyone who books client meetings uses the shared calendar, and it sends a confirmation to the client's contact."

Exercise 2. Write the four review questions for a small problem you solved recently.

**Suggested answer:** For example: "What helped: asking a colleague early. What slowed us: nobody knew who owned the login. Change: add the owner to the project sheet on day one."

Exercise 3. Rewrite this blaming sentence: "Sam lost the file because he is careless."

**Suggested answer:** "The file was saved only on one laptop. We will move important files to the shared folder and back them up."
